## 這個技術解決什麼問題

6.1 的股票題是狀態機 DP 的「有劇情版」，本節則是它的**素顏版**：

> **合法性只取決於相鄰兩個被選元素的關係**（一升一降交替、乘積正負、奇偶位置、相鄰不能同時選），而這種關係只有**少數幾種互斥的模式**。

於是狀態長成：

$$f(i,\,m) = \text{以第 } i \text{ 個元素結尾、且處於模式 } m \text{ 時的最優值（或方案數）}, \qquad m \in M,\ |M| = O(1).$$

**與 4.2 LIS 的分野極清楚**：

| | 狀態 | 狀態數 | 例 |
| --- | --- | --- | --- |
| **本節** | 位置 × **常數個模式** | $O(n)$ | 376、1567、1911、2222、2708 |
| 4.2 LIS | 位置（模式 = 「結尾的數值」，與輸入有關） | $O(n)$ 但轉移要掃 $O(n)$ | 300、673 |
| 7.4 合法子序列 | 位置 × **結尾的數值特徵**（公差、比例） | $O(n\cdot V)$ 或用雜湊 | 446、1027 |

**「模式數是常數」帶來的紅利**：轉移 $O(1)$ ⇒ **整題一遍掃描、$O(n)$ 時間、$O(1)$ 空間**。**這是本節所有題目的共同終點。**

**典型題與它的模式集合**：

| 題 | 模式集合 $M$ |
| --- | --- |
| 376 擺動序列 | {最後一步上升, 最後一步下降} |
| 1567 乘積為正數的最長子陣列 | {乘積為正, 乘積為負} |
| 1911 最大子序列交替和 | {已選偶數個, 已選奇數個} |
| 2222 選擇建築 | {`0`, `1`, `01`, `10`}（前綴形態） |
| 2708 一個小組的最大實力值 | {目前最大, 目前最小} |
| 2786 訪問陣列使分數最大 | {結尾是偶數, 結尾是奇數} |

## 狀態／資料結構定義

**通式**：

$$f(i,\,m) \;=\; \operatorname*{opt}_{\substack{m' \in M \\ (m' \xrightarrow{\ a_i\ } m)\ \text{合法}}} \Big( f(i-1,\,m') \ \diamond\ w(m',\,m,\,a_i) \Big).$$

**兩種語意，務必先想清楚**（**這是本節最常見的混淆來源** ✘）：

| 語意 | 寫法 | 答案 | 例 |
| --- | --- | --- | --- |
| **釘住結尾**：必須以 $a_i$ 結尾 | $f(i,m)$ 只能由 $f(i-1,\cdot)$ 接上 $a_i$ | $\max_{i,m} f(i,m)$ | 1567（要求連續）、53 |
| **前綴最優**：不要求以 $a_i$ 結尾 | $f(i,m)$ 額外允許 $f(i-1,m)$（「跳過 $a_i$」的自環） | $f(n-1,\cdot)$ | 376、1911、2708 |

**「連續」的題目必須釘住結尾**（4.1.1 定理 6：連續 ⇒ 釘住結尾），**「子序列」的題目兩種都行，但前綴最優版才能 $O(1)$ 空間** ✔。

**識別元素（單位元）的選擇**（2.1 定理 3）：

- 求 $\max$ ⇒ 不可達寫 $-\infty$；
- 求長度且「長度 0 = 不存在」⇒ **用 0 表示不存在時要特別小心**，因為 0 同時是合法的「空」長度 ✘（定理 3）；
- 計數 ⇒ 不可達寫 0，起點寫 1。

## 不變量或正確性證明

### 定理 1（常數模式狀態機的正確性）

*不變量*：$f(i,m)$ 恰為「所有在位置 $i$ 處於模式 $m$ 的合法方案」的最優值。

*證明*（對 $i$ 歸納）。歸納步的關鍵是：**任一在位置 $i$ 處於模式 $m$ 的方案，其在位置 $i-1$ 的模式 $m'$ 是唯一確定的**（模式是由「已選元素的關係」定義的，而 $a_i$ 的加入只改變最後一步）⇒ 按 $m'$ 劃分**互斥且窮盡** ✔；由歸納假設每個 $m'$ 分支取到最優 ⇒ 取 $\operatorname{opt}$ 後仍最優 ✔。$\square$

**這個證明依賴兩個前提，兩者缺一不可**：

1. **馬可夫性**：位置 $i$ 能取哪些模式，只由位置 $i-1$ 的模式與 $a_i$ 決定，**不依賴更早的歷史** ✔。若「能不能接」還要看倒數第二個被選元素（如 446 等差數列的公差），**模式集合就不是常數，得升級到 7.4** ✘。
2. **模式劃分是完備的**：$M$ 必須涵蓋所有可能的「歷史摘要」。**漏一個模式，DP 會靜默地少算一批方案，而且測資小的時候常常剛好對** ✘——**這是本節最陰險的錯誤。**

> **自檢法**：拿一組小輸入，手動列出所有合法方案，按你定義的模式分類。**若有方案分不進任何一類，或分進兩類，模式集合就錯了。**

### 定理 2（**376 擺動序列：為什麼只看相鄰一步就夠**）

*設定*：`up`、`down` 分別表示「掃到目前為止，最後一步為上升 / 下降的最長擺動子序列長度」（**前綴最優語意，不釘住結尾**）。

*命題*：若 $a_i > a_{i-1}$，則 $\mathit{up}_i = \mathit{down}_{i-1} + 1$、$\mathit{down}_i = \mathit{down}_{i-1}$；若 $a_i < a_{i-1}$ 則對稱；若 $a_i = a_{i-1}$ 則兩者都不變。

*證明*（只證關鍵的 $\ge$ 方向，即 $a_i > a_{i-1} \Rightarrow \mathit{up}_i \ge \mathit{down}_{i-1}+1$；$\le$ 方向由定義顯然）。

取一個達到 $\mathit{down}_{i-1}$ 的最優擺動子序列 $S$，設它的結尾索引為 $j \le i-1$。

- **情形 A：$a_i > a_j$。** 直接把 $a_i$ 接在 $S$ 後面，最後一步變上升 ⇒ 長度 $\mathit{down}_{i-1}+1$ ✔。
- **情形 B：$a_i \le a_j$。** 由 $a_i > a_{i-1}$ 得 $a_j \ge a_i > a_{i-1}$，所以 $j \ne i-1$，即 $j < i-1$。設 $S$ 的倒數第二個元素為 $a_{j'}$，因為最後一步是下降，$a_{j'} > a_j$。

  **把 $S$ 的結尾 $a_j$ 換成 $a_{i-1}$**：新的最後一步是 $a_{j'} \to a_{i-1}$，而 $a_{j'} > a_j \ge a_i > a_{i-1}$ ⇒ 仍是下降 ✔，長度不變、結尾索引變成 $i-1$。再接上 $a_i$（因為 $a_i > a_{i-1}$）⇒ 長度 $\mathit{down}_{i-1}+1$ ✔。

兩種情形都達成 ✔。$\square$

**這是一個標準的交換論證**（4.1.1 定理 1、4.2.2 定理 2 用過同一格式）：**「最優解可以被改造成具有我想要的形狀，且不變差」**。

**它解釋了一件反直覺的事**：DP 明明應該要枚舉「上一個被選元素是誰」（$O(n^2)$），**但擺動序列只看 $a_{i-1}$ 就夠——因為情形 B 的替換保證了「結尾一定可以搬到 $i-1$」** ✔。

**推論 2.1（貪心版）**：答案 $=$ 「差分序列去掉 0 之後，符號變號的次數 $+\,1$」。**這正是把上面的遞推展開後的閉式**——**兩種寫法等價，但 DP 版才看得出為什麼對。**

**⚠ 相等元素**：$a_i = a_{i-1}$ 時兩個值都不變（**不能算成上升也不能算成下降**）。**`[1,1,1]` 的答案是 1，不是 3** ✘——**這是本題唯一的邊界陷阱。**

### 定理 3（**1567：「0」同時代表「長度 0」與「不存在」的陷阱**）

*設定*：$\mathit{pos}_i$ / $\mathit{neg}_i$ = 以 $a_i$ 結尾、乘積為正 / 負的最長**連續**子陣列長度。

*轉移*：

$$a_i > 0:\quad \mathit{pos}_i = \mathit{pos}_{i-1} + 1, \qquad \mathit{neg}_i = \begin{cases}\mathit{neg}_{i-1}+1 & \mathit{neg}_{i-1} > 0\\ 0 & \mathit{neg}_{i-1} = 0\end{cases}$$

$$a_i < 0:\quad \mathit{pos}_i = \begin{cases}\mathit{neg}_{i-1}+1 & \mathit{neg}_{i-1} > 0\\ 0 & \mathit{neg}_{i-1}=0\end{cases}, \qquad \mathit{neg}_i = \mathit{pos}_{i-1}+1$$

$$a_i = 0:\quad \mathit{pos}_i = \mathit{neg}_i = 0.$$

*命題*：$\mathit{neg}_{i-1}=0$ 時**必須**把結果寫成 0 而非 1。

*證明*。$\mathit{neg}_{i-1}=0$ 的語意是「**不存在**以 $a_{i-1}$ 結尾且乘積為負的子陣列」，而不是「有一個長度為 0 的負乘積子陣列」——**長度為 0 的空乘積是 $1 > 0$，是正的** ✔。

若誤寫成 $\mathit{neg}_{i-1}+1 = 1$，就等於宣稱「$a_i$ 自己一個元素的乘積是正的」，**但此時 $a_i < 0$，矛盾** ✘。$\square$

> **這是 2.1 定理 3「識別元素」的實戰版**：**當你用同一個數值（0）承載兩種語意（「長度 0」與「不可達」）時，遲早會撞車。**
> **兩種正解**：(a) 像上式那樣顯式判斷 $>0$；(b) **把不可達寫成 $-\infty$，讓 $-\infty + 1$ 依然是 $-\infty$，轉移就不用分支** ✔——**後者更不容易錯，強烈推薦。**

**$a_i = 0$ 的處理**：0 把連續段截斷，兩個狀態都歸零 ✔。

### 定理 4（**1911 就是 122 買賣股票——加一個價格為 0 的虛擬第 0 天**）

*設定*：子序列 $a_{i_0}, a_{i_1}, \dots$ 的交替和為 $a_{i_0} - a_{i_1} + a_{i_2} - \cdots$，求最大值（$a_i \ge 1$）。

*命題*：把它看成「一開始就免費持有一股」的 122，答案為

$$a_0 + \sum_{i\ge 1}\max\big(0,\ a_i - a_{i-1}\big).$$

*證明*。先看遞推。令 $g_i$ / $h_i$ 為「已選奇數 / 偶數個元素」的最大交替和：

$$g_i = \max(g_{i-1},\ h_{i-1} + a_i), \qquad h_i = \max(h_{i-1},\ g_{i-1} - a_i).$$

**與 6.1 的 $f(i,0)=\max(f(i-1,0),\,f(i-1,1)+p_i)$、$f(i,1)=\max(f(i-1,1),\,f(i-1,0)-p_i)$ 逐字相同**，對應關係 $g \leftrightarrow$ 未持有、$h \leftrightarrow$ 持有 ✔。

**唯一的差別在初始化**：122 是「未持有 $=0$、持有 $=-\infty$」，1911 是「偶數個 $=0$、奇數個 $=-\infty$」——**在對應關係下，1911 相當於「持有 $=0$」，也就是一開始就白拿一股** ✔。

「白拿一股」等價於**在最前面插入一天，價格為 $0$，並在那天買入**。於是套用 6.1 定理 2 的閉式：

$$\text{答案} = \sum_{i\ge 0}\max(0,\ a_i - a_{i-1}) \quad\text{（其中 } a_{-1} = 0\text{）} = \max(0, a_0) + \sum_{i\ge1}\max(0,a_i-a_{i-1}).$$

由題目保證 $a_i \ge 1 > 0$ ⇒ 第一項就是 $a_0$ ✔。$\square$

**驗算**：$[4,2,5,3] \Rightarrow 4 + 0 + 3 + 0 = 7$ ✔（最優子序列 $4-2+5$）；$[6,2,1,2,4,5] \Rightarrow 6 + 0+0+1+2+1 = 10$ ✔。

> **這種「兩題其實是同一個狀態機、只差初始化」的觀察，是狀態機 DP 最大的複利。** 看到新題先問：**它的狀態圖跟我見過的哪一張一樣？**

**⚠ 前提**：閉式解依賴 $a_i > 0$。**若允許 $a_i \le 0$，$\max(0,a_0)$ 那一項就不能簡化成 $a_0$**（而遞推版本永遠正確）✔——**這也是「先寫遞推、確認後再壓成閉式」的理由。**

### 定理 5（**2222：計數型狀態機必須是嚴格劃分**）

*設定*：字串只含 `0`/`1`，求形如 `010` 或 `101` 的長度 3 子序列個數。

*命題*：維護四個計數器 $c_0, c_1, c_{01}, c_{10}$（分別是「已匹配 `0`」「已匹配 `1`」「已匹配 `01`」「已匹配 `10`」的方案數），掃到字元 $s_i$ 時：

$$s_i = \texttt{'0'}: \quad \mathit{ans} \mathrel{+}= c_{10}, \quad c_{01} \mathrel{+}= c_1, \quad c_0 \mathrel{+}= 1;$$
$$s_i = \texttt{'1'}: \quad \mathit{ans} \mathrel{+}= c_{01}, \quad c_{10} \mathrel{+}= c_0, \quad c_1 \mathrel{+}= 1.$$

*證明*。**按「第三個字元的位置 $i$」劃分**所有答案：每個合法三元組恰好有一個第三字元位置 ⇒ **互斥且窮盡** ✔（1.2 定理 2：**計數必須是嚴格劃分，不能像 $\max$ 那樣容許重疊覆蓋**）。

固定 $i$ 後，$c_{10}$（$s_i=\texttt{'0'}$ 時）恰為「在 $i$ 之前形如 `10` 的二元組個數」——由歸納假設成立 ✔。$\square$

**⚠ 更新順序至關重要**：必須**先累加答案、再更新較短的前綴計數**。若先做 $c_{01} \mathrel{+}= c_1$ 再 $\mathit{ans} \mathrel{+}= c_{10}$，順序其實無妨；**但若先做 $c_0 \mathrel{+}= 1$ 再 $c_{01} \mathrel{+}= c_1$，就會讓 $s_i$ 自己同時扮演兩個角色** ✘。

> **通則：狀態機計數的更新順序必須是「從長到短」**（先用舊值算長的，再更新短的），**這與 3.1 0-1 背包倒序、2.1 定理 2「先讀後寫」是同一條規則** ✔。

**溢位**：$n \le 10^5$ 時三元組數量可達 $\binom{n}{3} \approx 1.7\times10^{14}$ ⇒ **必須用 `long long`** ✘。

### 定理 6（**2708：乘積型要同時維護最大與最小**）

*命題*：求子序列乘積的最大值時，狀態必須是一對 $(\mathit{mx}_i,\ \mathit{mn}_i)$：

$$\mathit{mx}_i = \max\big(\mathit{mx}_{i-1},\ \ \mathit{mx}_{i-1}\cdot a_i,\ \ \mathit{mn}_{i-1}\cdot a_i,\ \ a_i\big),$$
$$\mathit{mn}_i = \min\big(\mathit{mn}_{i-1},\ \ \mathit{mx}_{i-1}\cdot a_i,\ \ \mathit{mn}_{i-1}\cdot a_i,\ \ a_i\big).$$

*證明*。轉移函數 $x \mapsto x\cdot a_i$ 是**單調函數**：$a_i > 0$ 時單調遞增、$a_i < 0$ 時單調遞減、$a_i = 0$ 時常數。

**單調函數把區間的端點映到區間的端點** ⇒ $\{x\cdot a_i : x \in [\mathit{mn}_{i-1},\ \mathit{mx}_{i-1}]\}$ 的極值只可能在 $\mathit{mn}_{i-1}$ 或 $\mathit{mx}_{i-1}$ 取到 ✔ ⇒ **只保留這兩個值就足夠**，不必記整個可達集合 $\square$

**這正是 1.3 定理 4 的複用**——**判準：轉移對「上一步的值」是單調的 ⇒ 保留最大與最小兩個代表即可。**

**四個候選項各自的必要性**（少一個就錯 ✘）：

| 候選 | 對應決策 | 少了會怎樣 |
| --- | --- | --- |
| $\mathit{mx}_{i-1}$ | 不選 $a_i$ | $a_i$ 為負數時被迫選入 |
| $\mathit{mx}_{i-1}\cdot a_i$ | 接在最大值後 | 正常情形算不出來 |
| $\mathit{mn}_{i-1}\cdot a_i$ | 接在最小值後 | **負負得正的機會全丟失** |
| $a_i$ | **從 $a_i$ 重新開始** | 前綴全是 0 時算不出來 |

**⚠ 溢位**：2708 的 $n \le 13$、$|a_i| \le 9$ ⇒ 乘積可達 $9^{13} \approx 2.5\times10^{12}$ ⇒ **`long long` 必要** ✘。

**⚠ 零**：$a_i = 0$ 時兩個狀態都會被拉到 0。由於「不選 $a_i$」這條分支存在，**0 不會污染答案** ✔；但若題目改成連續子陣列（152），**0 必須把狀態重置**，兩者不同。

## 時間與空間複雜度

| 題 | 時間 | 空間 |
| --- | --- | --- |
| 376、1567、1911、2222、2708、2786 | $O(n)$ | $O(1)$ |
| 一般式 | $O(n\cdot|\delta|)$，$|\delta| = $ 轉移邊數 | $O(|M|)$ |

**$O(1)$ 空間的前提**：$f(i,\cdot)$ 只依賴 $f(i-1,\cdot)$ ⇒ 每個模式一個變數即可 ✔。

**⚠ 同時更新的陷阱**：把 $f(i-1,\cdot)$ 壓成變數後，**同一輪內的更新會互相污染**。兩種安全寫法：

1. **先把舊值抄進暫存變數**（`int oldUp = up, oldDown = down;`），再一起更新 ✔；
2. **確認更新順序不會讀到本輪的新值**（如定理 2 的 376，$\mathit{up}$ 只讀 $\mathit{down}$ 的舊值、$\mathit{down}$ 在該分支不變 ⇒ 可以就地寫）。

**寫法 1 永遠安全，寫法 2 需要逐題論證**——**趕時間就用寫法 1** ✔。**這是 2.1 定理 2 在「變數層級」的重述。**

**溢位速查**：計數型（2222）$\Rightarrow$ `long long` 或取模；乘積型（2708）$\Rightarrow$ `long long`；長度型（376、1567）$\Rightarrow$ `int` 足夠。

## 與相似技巧的比較

- **與 6.1 買賣股票**：**同一個框架，本節是它的抽象形式。** 1911 甚至就是 122 換個初始化（定理 4）。
- **與 4.2 LIS**：LIS 的「模式」是結尾的數值，**模式數與輸入同階** ⇒ 轉移要 $O(\log n)$ 或 $O(n)$；本節模式數是常數 ⇒ 轉移 $O(1)$。**376 擺動序列看起來很像 LIS，但因為只需比較相鄰元素（定理 2 的交換論證），退化成常數模式** ✔。
- **與 7.3 子陣列 DP**：53 最大子陣列和是「單模式」的本節特例；152 乘積最大子陣列則是「$(\max,\min)$ 雙模式 + 連續」版本。**本節的 2708 是它的子序列版。**
- **與 7.4 合法子序列 DP**：**分界線是「模式數是否為常數」。** 一旦轉移要看「上一個被選元素的具體數值」（公差、比例），模式就爆炸，得改用雜湊表或多開一維。
- **與貪心**：376 有等價的貪心（推論 2.1）、1911 有閉式（定理 4），**但兩者的正確性都是先由 DP 證出來的。遇到新題先寫 DP，確認後再壓縮。**
- **與 9 章狀壓 DP**：模式若是「一個子集合」而非有限標籤，就是狀壓。**判準：模式的資訊量是 $O(1)$ 還是 $O(n)$ bits。**

## 本節重點速查

**框架**：$f(i,m) = \operatorname{opt}_{m'\to m}\big(f(i-1,m') \diamond w\big)$，$|M| = O(1)$ ⇒ **$O(n)$ 時間、$O(1)$ 空間**。
**兩種語意**：**釘住結尾**（連續型，答案取 $\max_{i,m}$）vs **前綴最優**（子序列型，多一條「跳過 $a_i$」的自環，答案取 $f(n-1,\cdot)$）。
**定理 1**：正確性靠「位置 $i-1$ 的模式唯一確定」的互斥窮盡劃分；前提是**馬可夫性**與**模式集合完備**。自檢法：小輸入手動分類，看有沒有方案落單或重複。
**定理 2（376）**：只看相鄰一步就夠，靠**交換論證**（結尾可以搬到 $i-1$）。相等元素兩邊都不算，`[1,1,1]` 答案是 1。
**定理 3（1567）**：**0 不能同時代表「長度 0」與「不存在」** ✘。改用 $-\infty$ 當不可達值，轉移就不必分支。
**定理 4（1911）**：**= 122 加一個價格 0 的虛擬第 0 天**，閉式 $a_0+\sum_{i\ge1}\max(0,a_i-a_{i-1})$（依賴 $a_i>0$）。
**定理 5（2222）**：計數型按「最後一個字元的位置」嚴格劃分；**更新順序必須從長到短**，否則同一字元扮演兩個角色 ✘。`long long`。
**定理 6（2708）**：乘積型維護 $(\max,\min)$ 一對，理由是**乘法對上一步的值單調 ⇒ 極值只在端點**（1.3 定理 4）。四個候選缺一不可，尤其 $a_i$ 自己那一項。
**最常見的實作錯**：把 $f(i-1,\cdot)$ 壓成變數後**就地更新互相污染** ⇒ **先抄舊值到暫存變數再一起更新。**
