## 這個技術解決什麼問題

**「在 $[0,N]$（或 $[L,R]$）裡，有幾個數滿足某個逐位可判斷的條件？」而 $N$ 大到 $10^9$、$10^{18}$ 甚至是一個 100 位的字串。**

暴力是 $O(N)$；數位 DP 把它壓成

$$O\big(\underbrace{\mathit{len}}_{\text{位數}}\times\underbrace{|\mathit{st}|}_{\text{狀態數}}\times\underbrace{D}_{\text{進位基底}}\big),$$

$N=10^{18}$ 時 $\mathit{len}=19$ ⇒ **從 $10^{18}$ 降到幾百次運算**。

**核心心法只有一句**：

> **不要枚舉「數」，要枚舉「數的前綴」。**
> 所有共用同一個「(位置, 狀態)」的前綴，對答案的貢獻**完全相同** ⇒ 可以合併記憶化。

這句話的兩個限定條件，就是本節全部的技術含量：

1. **「貼著上界」的前綴不能與「已經自由」的前綴合併**（定理 1）；
2. **「還沒開始填有效數字」的前綴（前導零）有時也不能合併**（定理 2）。

**這個技術能不能用，取決於一件事**：條件能不能**逐位累積成一個小狀態**（定理 4）。

| 條件 | 狀態 | 可行 |
| --- | --- | --- |
| 各位數字互不相同（357、1012、2376） | 已用數字的 10 位遮罩 | ✔ $2^{10}$ |
| 二進位不含連續 1（600） | 上一位是不是 1 | ✔ $2$ |
| 相鄰數位差 1（2801 步進數字） | 上一位是什麼 | ✔ $10$ |
| 數位和落在 $[\mathit{lo},\mathit{hi}]$（2719） | 目前的數位和 | ✔ $\le9\mathit{len}$ |
| 只能用給定的數字（902） | 無（只是限制可選數字） | ✔ $1$ |
| 旋轉 180° 後仍合法且不同（788） | 是否已出現過會變的數字 | ✔ $2$ |
| **這個數是質數** | — | **✘ 無法逐位累積** |

## 狀態／資料結構定義

把 $N$ 寫成字串 $s=s_0s_1\cdots s_{\mathit{len}-1}$（最高位在前），定義

$$f(i,\ \mathit{st},\ \mathit{isLimit},\ \mathit{isNum}) = \text{「已經填好第 } 0..i-1 \text{ 位、後續還能填出幾個合法數」}.$$

四個參數的意義：

| 參數 | 意義 | 是否進記憶化表 |
| --- | --- | --- |
| $i$ | 目前要填第幾位（$0..\mathit{len}$） | **✔ 是** |
| $\mathit{st}$ | 題目要求的累積狀態（上表第二欄） | **✔ 是** |
| $\mathit{isLimit}$ | 前 $i$ 位是否**與 $N$ 完全相同**（此時第 $i$ 位最多只能填到 $s_i$） | **✘ 否**（定理 1） |
| $\mathit{isNum}$ | 前 $i$ 位是否**已經填過至少一個有效數字**（否則還在前導零階段） | **✘ 否**（定理 1／2） |

**邊界**：$i=\mathit{len}$ 時回傳 $[\ \mathit{isNum}\ \text{且}\ \mathit{st}\ \text{合法}\ ]$（若題目把 $0$ 也算一個合法數，就回傳 $1$）。

**第 $i$ 位的可選範圍**：

$$d\in\big[\ \mathit{isNum}\ ?\ 0:0,\quad \mathit{isLimit}\ ?\ s_i:D-1\ \big],$$

外加一條**「跳過這一位（繼續前導零）」的分支**，只在 $\lnot\mathit{isNum}$ 時存在，且它會保持 $\mathit{isNum}=\text{false}$、$\mathit{isLimit}=\text{false}$。

**記憶化表**：只用 $(i,\mathit{st})$ 索引，大小 $\mathit{len}\times|\mathit{st}|$，**初值填 $-1$**。

## 不變量或正確性證明

### 定理 1（**記憶化只能發生在 $\lnot\mathit{isLimit}\ \wedge\ \mathit{isNum}$——而且這不影響複雜度**）

*命題*：

**(a) 必要性**：把 $\mathit{isLimit}$ 不同的狀態合併記憶化是**錯的**。
**(b) 無害性**：不對 $\mathit{isLimit}=\text{true}$ 或 $\mathit{isNum}=\text{false}$ 的狀態記憶化，**只多花 $O(\mathit{len}\cdot D)$**，不改變複雜度。

*證明*。

**(a)** 反例。設 $N=12$（$\mathit{len}=2$，$D=10$），數「$[0,12]$ 裡有幾個數」，$\mathit{st}$ 為空（只有一個狀態）。正確答案 $13$。

遞迴從 $f(0,\cdot,\text{true},\text{false})$ 出發，第 0 位可填 $0$ 或 $1$：

- 填 $0$ ⇒ 進入 $f(1,\cdot,\ \boxed{\text{false}},\ \cdot)$，第 1 位可填 $0..9$ ⇒ **10**；
- 填 $1$ ⇒ 進入 $f(1,\cdot,\ \boxed{\text{true}},\ \cdot)$，第 1 位只能填 $0,1,2$ ⇒ **3**。

若記憶化表以 $(i,\mathit{st})=(1,\varnothing)$ 為鍵而**不含 $\mathit{isLimit}$**，先算的那一支（$10$）會被第二支直接讀走 ⇒ 總數變成 $10+10=20$ ✘。**$\mathit{isLimit}$ 改變了可選數字的範圍，所以它是狀態的一部分，不能被合併。**

**(b)** 關鍵觀察：

- **對每個 $i$，滿足 $\mathit{isLimit}=\text{true}$ 的前綴恰好只有一個**——就是 $s_0s_1\cdots s_{i-1}$ 本身 ✔。所以整棵遞迴樹裡，$\mathit{isLimit}=\text{true}$ 的節點**至多 $\mathit{len}$ 個**。
- **對每個 $i$，滿足 $\mathit{isNum}=\text{false}$ 的前綴也恰好只有一個**——全是前導零 ✔。同樣至多 $\mathit{len}$ 個。

每個這樣的節點花 $O(D)$ ⇒ 額外成本 $O(\mathit{len}\cdot D)$，相對於主體的 $O(\mathit{len}\cdot|\mathit{st}|\cdot D)$ **可以忽略** ✔。$\square$

*推論 1.1*：**所以標準寫法就是「$\mathit{isLimit}$ 或 $\lnot\mathit{isNum}$ 時直接算、不讀不寫記憶化表」。** 這既正確又不損失效率——**不要為了「省」而把它們塞進表裡，那只會讓表大 4 倍且容易寫錯。**

*推論 1.2*：$\mathit{isLimit}=\text{true}$ 的分支中，**只有填 $d=s_i$ 那一支會延續 $\mathit{isLimit}=\text{true}$**，其餘 $d<s_i$ 都變成 false ✔。這條「每層只有一條路保持貼界」正是 (b) 成立的原因。

### 定理 2（**$\mathit{isNum}$（前導零）什麼時候可以省掉**）

*設定*：$\mathit{isNum}$ 存在的唯一目的，是區分「還沒開始的 0」與「真正填下的 0」。

*命題*：設狀態更新函數為 $\mathit{st}\mapsto g(\mathit{st},d)$、初始狀態 $\mathit{st}_0$。若

$$g(\mathit{st}_0,\ 0) = \mathit{st}_0\qquad\text{且}\qquad \text{「填 } 0 \text{」在首位永遠合法},$$

則**前導零與真正的 0 在狀態上不可區分** ⇒ **可以省略 $\mathit{isNum}$**，直接把所有數當成定長 $\mathit{len}$ 位來數（不足補前導零）。

*證明*。省略 $\mathit{isNum}$ 相當於把每個 $k$ 位數 $x$ 當成 $\mathit{len}$ 位字串（前面補 $\mathit{len}-k$ 個 $0$）來處理。由條件，這些補上的 $0$ 逐次作用後狀態仍是 $\mathit{st}_0$ ⇒ 到達真正首位時的狀態與「從 $\mathit{st}_0$ 開始」完全相同 ⇒ 之後的計數一致 ✔。又補零是**單射**（每個 $x$ 只有一種補法）⇒ 不重不漏 ✔。$\square$

*套用（這張表要背）*：

| 條件 | $g(\mathit{st}_0,0)=\mathit{st}_0$？ | $\mathit{isNum}$ |
| --- | --- | --- |
| 數位和落在區間（2719） | ✔ 加 0 不改變和 | **可省** |
| 統計某數字出現次數（10.2 的 233） | ✔（統計的不是 0 時） | **可省** |
| 二進位不含連續 1（600） | ✔ 前導 0 不會製造連續 1 | **可省** |
| **各位數字互不相同（357、2376）** | ✘ 前導 0 會佔掉「數字 0 已用」 | **必須留** |
| **相鄰數位差 1（2801 步進數字）** | ✘ 前導 0 之後接 1 會被誤判成 $0\to1$ 的合法步進 | **必須留** |
| **對稱／位數相關（2843）** | ✘ 位數本身就是條件的一部分 | **必須留** |

*⚠ 最陰險的一種錯*：$\mathit{isNum}$ 該留卻省了，**在小測資上常常剛好對**——因為前導零只影響「位數比 $\mathit{len}$ 短」的數，$N$ 很小時這些數很少。**一定要用 $N=100$、$N=1000$ 這種「位數跨越」的輸入去測。**

### 定理 3（**$[L,R]$ 的兩種正確處理**）

**做法甲（差分）**：$\mathrm{ans}(L,R)=F(R)-F(L-1)$，其中 $F(X)$ 是 $[0,X]$ 的計數。

*前提*：**$L-1$ 算得出來** ✔。$L$ 是 `int`／`long long` 時沒問題；**$L$ 是 100 位的字串時，要自己寫字串減一**（且要處理 $L=0$、退位、去掉前導零）⚠。

**做法乙（雙界）**：把狀態改成 $f(i,\mathit{st},\mathit{isLow},\mathit{isHigh},\mathit{isNum})$，$\mathit{isLow}$ 表示「前 $i$ 位與 $L$ 完全相同」（此時第 $i$ 位不得小於 $L_i$），$\mathit{isHigh}$ 表示貼著 $R$。第 $i$ 位的範圍是

$$\big[\ \mathit{isLow}\ ?\ L_i:0,\quad \mathit{isHigh}\ ?\ R_i:D-1\ \big].$$

*正確性*：與定理 1 完全同構——**對每個 $i$，$\mathit{isLow}=\text{true}$ 的前綴唯一、$\mathit{isHigh}=\text{true}$ 的前綴唯一** ⇒ 兩者都不進記憶化表，額外成本 $O(\mathit{len}\cdot D)$ ✔。而枚舉範圍的交集恰好對應 $[L,R]$ 中的數 ✔。

*何時選哪個*：

| 情境 | 選 |
| --- | --- |
| $L,R$ 是普通整數 | **甲**（程式短一半） |
| $L,R$ 是超長字串（2719、2801） | **乙**（免寫大數減一） |
| $L,R$ 位數不同 | **乙 需要把 $L$ 補前導零到與 $R$ 等長** ⚠，補完後 $\mathit{isLow}$ 的語意要配合 $\mathit{isNum}$ 小心處理；此時**甲 反而單純** |

*⚠ 一個常見的越界*：做法甲若 $L=0$，$L-1=-1$ ⇒ 必須特判 $F(-1)=0$ ✔。

### 定理 4（**什麼樣的條件能做數位 DP：兩個形式要求**）

*命題*：條件 $P(x)$ 可用數位 DP 計數，**若存在**一個有限狀態集合 $\mathcal{S}$、初始狀態 $\mathit{st}_0$、轉移 $g:\mathcal{S}\times\{0..D{-}1\}\to\mathcal{S}$ 與接受集 $A\subseteq\mathcal{S}$，使得

$$P(x)\iff g^*(\mathit{st}_0,\ \text{digits}(x))\in A.$$

換句話說：**$P$ 必須是一個「數字串上的有限自動機語言」**。

*兩個實務判準*：

- **(i) 增量性**：讀入下一位後，新狀態只由「舊狀態 + 這一位」決定，**不需要回看更前面的位** ✔。
- **(ii) 完備性**：兩個前綴若狀態相同，則**任何後綴接上去的合法性完全一致** ✔（這就是 1.1 定理 4 的無後效性）。

*套用範例（788 旋轉數字）*：把數字分成三類——$\{0,1,8\}$ 旋轉後不變、$\{2,5,6,9\}$ 旋轉後變成另一個合法數字、$\{3,4,7\}$ 旋轉後非法。條件「旋轉後仍是合法數且**與原數不同**」$\iff$「不含 $\{3,4,7\}$」**且**「至少含一個 $\{2,5,6,9\}$」。

⇒ $\mathcal{S}=\{\text{尚未出現 }2569,\ \text{已出現}\}$，$|\mathcal{S}|=2$，$\{3,4,7\}$ 直接不枚舉（剪枝）✔。**條件被拆成「禁止集合」+「至少一次」兩塊，後者就是那 1 個位元**——這是數位 DP 最常見的狀態設計手法。

*反例（不能做的）*：

- **「$x$ 是質數」** ✘：質性不是有限自動機語言（讀完前綴無法用有限資訊決定）。
- **「$x$ 的各位重排後是回文」** ⚠：可以做，但狀態要是「各數字出現次數的奇偶」⇒ $2^{10}$ 個狀態（只需奇偶，不需完整計數）✔——**這說明「狀態太大」和「不能做」是兩回事，先想想能不能壓。**

*推論 4.1（狀態壓縮的兩個常用招）*：

1. **用「集合」取代「計數向量」**：只關心「用過沒用過」時，$2^{10}=1024$ 遠小於 $\prod(c_d+1)$ ✔（2376、357）。
2. **用「奇偶／模數」取代「精確值」**：只關心整除性或回文性時，狀態砍到 $2^{10}$ 或 $m$ ✔。

### 定理 5（**三個 $O(1)$ 閉式，拿來當單元測試**）

寫完數位 DP 後，**用這三條驗證**，比隨機測資有效得多：

**(a) 全部數字互不相同（357）**：$[0,10^n)$ 中各位互異的數有

$$1+\sum_{k=1}^{\min(n,10)} 9\cdot P(9,\ k-1),\qquad P(9,m)=\frac{9!}{(9-m)!}.$$

*驗算*：$n=1\Rightarrow1+9=10$ ✔；$n=2\Rightarrow1+9+81=91$ ✔。

*證明*：$k$ 位數（無前導零）：首位 9 種，其餘從剩下的 9 個數字中**有序**取 $k-1$ 個 ⇒ $9\cdot P(9,k-1)$ ✔；再加上 $x=0$ 這一個 ✔。$n>10$ 時鴿籠原理保證沒有更長的 ⇒ 上限取 $\min(n,10)$ ✔。

**(b) 二進位不含連續 1（600）**：長度 $k$ 的 0/1 字串中不含 `11` 的有 $F_{k+2}$ 個（$F_1=F_2=1$）。

*證明*：設 $a_k$ 為個數。首位為 0 ⇒ 後面自由（$a_{k-1}$）；首位為 1 ⇒ 第二位必為 0，其後自由（$a_{k-2}$）⇒ $a_k=a_{k-1}+a_{k-2}$，$a_1=2=F_3$、$a_2=3=F_4$ ⇒ $a_k=F_{k+2}$ ✔。

*用法*：令 $N=2^k-1$，你的程式應該回傳 $F_{k+2}$。$k=5\Rightarrow N=31\Rightarrow F_7=13$ ✔。

**(c) 單調性與差分**：對任意 $N$，

$$F(N)-F(N-1)\in\{0,1\},\qquad F(N)-F(N-1)=1\iff N\ \text{本身合法}.$$

*用法*：對 $N=0..2000$ 逐一驗證 $F(N)-F(N-1)$ 與暴力判斷一致 ⇒ **一次抓出所有 $\mathit{isLimit}$／$\mathit{isNum}$ 的錯誤**。**這是本節最有用的一條測試，強烈建議每題都跑一次。**

### 定理 6（**複雜度與狀態爆炸的判準**）

*命題*：總時間 $=O(\mathit{len}\cdot|\mathcal{S}|\cdot D)$，總空間 $=O(\mathit{len}\cdot|\mathcal{S}|)$。

*何時會爆*：

| 狀態設計 | $|\mathcal{S}|$ | $\mathit{len}=19$ 時 |
| --- | --- | --- |
| 上一位是什麼 | $10$ | $1900$ ✔ |
| 已用數字集合 | $2^{10}=1024$ | $2\times10^5$ ✔ |
| 數位和 | $\le9\cdot19=171$ | $3\times10^4$ ✔ |
| 數位和 $\times$ 已用集合 | $171\cdot1024$ | $3\times10^7$ ⚠ |
| **各數字出現次數（完整計數向量）** | $\prod(c_d+1)\approx20^{10}$ | **✘ 必爆** |

*對策*（推論 4.1）：**先問「這個維度真的需要精確值嗎？」**——多數時候「集合」「奇偶」「模 $m$」就夠 ✔。

*⚠ 一個容易忽略的乘數*：**若狀態依賴輸入本身**（例如 2719 的「數位和上限」由輸入給定），則**每次查詢都要重建記憶化表**，不能跨測資重用 ✘（見定理 5(c) 的測試會直接抓到這個錯）。反之若狀態與輸入無關（600、357），**可以只清一次表、跨查詢重用** ✔——多筆查詢時這是很大的加速。

## 時間與空間複雜度

| 項 | 值 |
| --- | --- |
| **時間** | $O(\mathit{len}\cdot|\mathcal{S}|\cdot D)$，加上 $O(\mathit{len}\cdot D)$ 的貼界／前導零開銷 |
| **空間** | $O(\mathit{len}\cdot|\mathcal{S}|)$ 的記憶化表 + $O(\mathit{len})$ 遞迴深度 |

**具體題目**：

| 題 | $\mathit{len}$ | $|\mathcal{S}|$ | 時間 |
| --- | --- | --- | --- |
| 357 各位不同 | $\le10$ | $2^{10}$ | $10^5$ ✔ |
| 600 不含連續 1 | $\le31$（二進位，$D=2$） | $2$ | $124$ ✔ |
| 788 旋轉數字 | $\le5$ | $2$ | $100$ ✔ |
| 902 給定數字集合 | $\le10$ | $1$ | $100$ ✔ |
| 2376 特殊整數 | $\le10$ | $2^{10}$ | $10^5$ ✔ |
| 2719 數位和區間 | $\le23$ | $\le400$ | $10^5$ ✔ |
| 2801 步進數字 | $\le100$ | $10$ | $10^4$ ✔ |

**全部都是 $10^5$ 以內**——**數位 DP 的複雜度幾乎從來不是瓶頸，出錯的永遠是邊界。**

**三個實務注意事項**：

1. **記憶化表用 `long long`**：$[0,10^{18}]$ 的計數可能超過 `int` ⚠。取模題則用 `int` + 模數。
2. **表的初值**：計數題用 $-1$ 表示「未計算」（$0$ 是合法答案，**不能拿來當哨兵**）✔。
3. **遞迴 vs 遞推**：$\mathit{len}\le100$ ⇒ 遞迴深度安全 ✔。**遞迴（記憶化搜尋）在數位 DP 上幾乎永遠是正確選擇**——遞推版要手動處理 $\mathit{isLimit}$ 的分層，容易寫錯而且不會更快。

## 與相似技巧的比較

- **與 10.2 統計價值總和**：本節數「有幾個」，10.2 數「加起來多少」。**狀態設計完全相同，差別只在回傳值從 $1$ 變成「貢獻」，而且通常要同時回傳 (個數, 總和) 兩個量**（因為每一位的貢獻要乘上「後面有幾種填法」）。**先把本節寫熟，10.2 只是換一個累加器。**
- **與 10.3 其他數位 DP**：10.3 的狀態花樣更多（餘數、乘積、二進位對稱），而且會做**構造**（求最小／第 $k$ 個合法數）——那是把本節的計數當作「分支容量」來做逐位貪心。**計數是構造的前置能力。**
- **與 1.1 定理 4（無後效性）**：定理 4 的 (i)(ii) 就是無後效性在字串上的版本。**數位 DP = 在「數字串」這個序列上做線性 DP，$\mathit{isLimit}$ 是唯一的額外複雜度。**
- **與 9 章狀壓**：357／2376 的狀態是「已用數字的 $2^{10}$ 遮罩」——**那是狀壓，只是搬到了數位 DP 的骨架上。** 兩個技巧可以自由組合。
- **與有限自動機／AC 自動機**：定理 4 說白了就是「條件必須是正規語言」。**若條件是「不含某些子字串」，狀態就是 AC 自動機的節點**——這是數位 DP 的自然推廣。
- **與排容原理**：「至少有 1 位重複」（1012）$=$ 全部 $-$「各位互不相同」。**「至少」型條件先取補集，幾乎永遠更好寫**——因為「互不相同」是可逐位維護的，「至少重複一次」則需要額外記「是否已重複」的位元 ⚠（兩種都可以，但補集版狀態少一半）。
- **與二分搜尋**：要求「第 $k$ 個合法數」時，可以用「二分 $X$ + 檢查 $F(X)\ge k$」，$O(\log N)$ 次數位 DP ✔。**這比逐位構造好寫，代價是多一個 $\log$。**

## 本節重點速查

- **骨架**：$f(i,\ \mathit{st},\ \mathit{isLimit},\ \mathit{isNum})$，記憶化表**只用 $(i,\mathit{st})$**。
- **定理 1**：$\mathit{isLimit}$／$\mathit{isNum}$ **不可**進表（反例：$N=12$ 會數成 20 而不是 13）；**不進表也不影響複雜度**，因為每層貼界的前綴唯一、全前導零的前綴唯一 ⇒ 只多 $O(\mathit{len}\cdot D)$。
- **定理 2**：$g(\mathit{st}_0,0)=\mathit{st}_0$ ⇒ **$\mathit{isNum}$ 可省**（數位和、統計某數字次數、不含連續 1）；否則**必須留**（各位互異、相鄰差 1、位數相關）。**該留卻省了，小測資常常剛好對。**
- **定理 3**：$[L,R]$ 用 **$F(R)-F(L-1)$**（普通整數）或**雙界 $\mathit{isLow}/\mathit{isHigh}$**（超長字串）。$L=0$ 要特判。
- **定理 4**：條件必須是**數字串上的有限自動機語言**——(i) 增量、(ii) 完備。「是質數」不行；「重排成回文」可以（狀態取各數字次數的**奇偶**）。
- **壓狀態兩招**：用**集合**取代計數向量；用**奇偶／模數**取代精確值。
- **定理 5（一定要跑）**：三個閉式自我檢驗——357 的 $1+\sum9P(9,k{-}1)$（$n=2\Rightarrow91$）；600 的 $F_{k+2}$（$N=31\Rightarrow13$）；**$F(N)-F(N-1)\in\{0,1\}$ 且等於 1 當且僅當 $N$ 合法**（對 $N=0..2000$ 全掃一遍，能抓出所有邊界錯誤）。
- **定理 6**：時間 $O(\mathit{len}|\mathcal{S}|D)$，實務上都在 $10^5$ 以內。**⚠ 狀態若依賴輸入，每次查詢都要清表；不依賴則可跨查詢重用。**
- **實作**：回傳值用 `long long`；記憶化初值用 $-1$（不能用 0）；一律寫記憶化搜尋，不要寫遞推。
