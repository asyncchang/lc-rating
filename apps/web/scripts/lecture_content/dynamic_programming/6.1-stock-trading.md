## 這個技術解決什麼問題

前面 1～5 章的狀態都是「**位置**」（前 $i$ 個、走到 $(i,j)$、切了 $t$ 段）。**買賣股票這一系列題目暴露了一個新需求：光知道「走到第 $i$ 天」不夠，還得知道「此刻手上有沒有股票」。**

$$\text{位置} \ \longrightarrow\ \text{位置} \times \text{身分}$$

**這就是狀態機 DP**：把「身分」（持有 / 未持有 / 冷凍中 / 已用幾次交易）當成狀態的一維，每一天在這些身分之間依固定規則轉移。

**為什麼一定要加這一維？** 因為若只記 $f(i)=$「前 $i$ 天的最大利潤」，**轉移時你無法判斷第 $i$ 天能不能賣**——賣的前提是先前買過，而 $f(i-1)$ 這個數字裡看不出這件事 ✘。**這正是 1.1 定理 4「無後效性檢查」的失敗案例：狀態不完整。**

**整個系列只有一張狀態機，加限制就是加點或加邊**：

| 題 | 限制 | 狀態機的改動 |
| --- | --- | --- |
| 121 | 只能買賣**一次** | 「持有」的入邊改成 $-p_i$（而非 $f(i-1,0)-p_i$） |
| 122 | 交易**無限次** | 基本狀態機，兩個點 |
| 714 | 無限次，每筆收**手續費** | 賣出的邊權減 $\mathit{fee}$ |
| 309 | 無限次，賣出後**冷凍一天** | 加第三個點「冷凍中」（或改讀 $f(i-2)$） |
| 123 | 至多 **2** 次 | 加一維交易次數 $j \in \{0,1,2\}$ |
| 188 | 至多 **$k$** 次 | 交易次數維度一般化 |

**學會這一節，等於一次拿下六題**——**而且它是第 6 章的原型：後面的 376 擺動序列、1911 交替和、2222 選擇建築，用的是同一套「以位置結尾 × 有限個模式」。**

## 狀態／資料結構定義

**基本兩態**（122、714）：

$$f(i,\,0) = \text{第 } i \text{ 天結束時\textbf{未持有}股票的最大利潤}, \qquad f(i,\,1) = \text{第 } i \text{ 天結束時\textbf{持有}股票的最大利潤}.$$

轉移（$p_i$ 為第 $i$ 天股價）：

$$f(i,0) = \max\big(\underbrace{f(i-1,0)}_{\text{不動}},\ \underbrace{f(i-1,1) + p_i}_{\text{今天賣}}\big), \qquad f(i,1) = \max\big(\underbrace{f(i-1,1)}_{\text{不動}},\ \underbrace{f(i-1,0) - p_i}_{\text{今天買}}\big).$$

**初始化**：$f(-1,0) = 0$（沒開始，沒利潤）、$f(-1,1) = -\infty$（**不可能在第 0 天之前就持有股票**）✔。實務上用 `-0x3f3f3f3f` 或直接寫 `f0 = 0, f1 = -prices[0]` 從第 1 天開始。

**加交易次數**（123、188）：

$$f(i,\,j,\,s) = \text{前 } i \text{ 天、\textbf{已完成（或已開啟）} } j \text{ 筆交易、目前身分為 } s \text{ 的最大利潤}.$$

**「$j$ 在買的時候加還是賣的時候加」兩種寫法都對，但必須全程一致**——混用是本題第一名的錯 ✘。本節統一採「**買入時 $j{+}1$**」：

$$f(i,j,1) = \max\big(f(i-1,j,1),\ f(i-1,j-1,0) - p_i\big), \qquad f(i,j,0) = \max\big(f(i-1,j,0),\ f(i-1,j,1) + p_i\big).$$

**加冷凍期**（309）：三態 $s \in \{\text{持有},\ \text{冷凍}(\text{今天剛賣}),\ \text{自由}(\text{未持有且可買})\}$；或維持兩態但買入時讀 $f(i-2,0)$（定理 5）。

**狀態機的圖論觀點**：把 $(i,s)$ 當成節點、轉移當成有向邊、$\pm p_i$ 當成邊權，**整個 DP 就是在一張分層 DAG 上求最長路** ✔。**分層保證無環 ⇒ 無後效性自動成立**（1.1 定理 4）。

## 不變量或正確性證明

### 定理 1（兩態狀態機的正確性）

*不變量*：對每個 $i$ 與 $s\in\{0,1\}$，$f(i,s)$ 等於「所有在第 $i$ 天結束時身分為 $s$ 的合法交易序列」的利潤上確界。

*證明*（對 $i$ 歸納）。

**基底** $i=0$：$f(0,0)=0$（什麼都不做）、$f(0,1)=-p_0$（買入）——這兩個是第 0 天結束時各身分唯一可能的方案 ✔。

**歸納步**：考慮任一在第 $i$ 天結束時身分為 $0$（未持有）的最優方案 $A$。第 $i$ 天，$A$ 只可能做兩件事之一：
- **什麼都不做** ⇒ 第 $i-1$ 天結束時也是未持有 ⇒ $A$ 的前綴是一個「第 $i-1$ 天未持有」的方案，利潤 $\le f(i-1,0)$；
- **賣出** ⇒ 第 $i-1$ 天結束時持有 ⇒ 前綴利潤 $\le f(i-1,1)$，加上今天收入 $p_i$。

（**不會有「今天買又今天賣」**：那等於什麼都沒做，利潤 0，已被第一種涵蓋 ✔。）

兩種情形**互斥且窮盡** ✔ ⇒ $A$ 的利潤 $\le \max$ 式的右邊。反向：右邊的兩個候選都對應到一個真實可行的方案（由歸納假設，前綴可實現）⇒ 取等 ✔。$s=1$ 對稱。$\square$

**這個證明用到的前提**：
1. **每天最多做一個動作**，且動作只依賴「昨天的身分」——若題目允許「同一天買賣多次」或「持有多股」，狀態就不完整 ✘；
2. **利潤可加**——每筆交易的收益不受其他交易影響。

### 定理 2（**122 的貪心 $\sum\max(0,\,p_i-p_{i-1})$ 為什麼正確**）

*命題*：交易次數無限制時，最大利潤 $= \displaystyle\sum_{i=1}^{n-1}\max(0,\ p_i - p_{i-1})$。

*證明*（兩個方向）。

**($\le$) 任何方案不超過它。** 任一方案是若干不重疊區間 $[b_1,s_1],\dots,[b_m,s_m]$，利潤 $=\sum_t (p_{s_t}-p_{b_t})$。**把每個區間的收益寫成差分的望遠鏡和**：

$$p_{s_t} - p_{b_t} = \sum_{i=b_t+1}^{s_t} (p_i - p_{i-1}) \ \le\ \sum_{i=b_t+1}^{s_t} \max(0,\ p_i - p_{i-1}).$$

由於區間**互不重疊**，把所有 $t$ 相加後每個差分項最多被用一次 ⇒ 總和 $\le \sum_i \max(0, p_i-p_{i-1})$ ✔。

**($\ge$) 這個值可以達到。** 對每個 $p_i > p_{i-1}$ 的 $i$，做一筆「第 $i-1$ 天買、第 $i$ 天賣」的交易。**這些長度為 1 的區間互不重疊**（區間 $[i-1,i]$ 只在端點相接，而端點相接是允許的：同一天先賣再買）✔ ⇒ 利潤恰為該和 ✔。$\square$

**「區間互不重疊」在 ($\le$) 方向是關鍵**——**這正是「同一天不能同時持有兩筆」這條規則的數學形式。**

**推論 2.1**：貪心與 DP 給出相同答案，但 **DP 才是可擴充的**。加上手續費（714）後貪心立刻失效：

> 反例：$p = [1,\,3,\,2,\,4]$，$\mathit{fee}=2$。
> 貪心式的「所有正差」= $(3-1)+(4-2)=4$，扣兩筆手續費得 $4-4=0$；
> 但一次交易 $1\to4$ 得 $3-2=1$ **更好** ✔。
> **手續費讓「合併交易」變得有價值，而逐日貪心看不到這件事** ✘。

**這是本節最值得記的教訓：貪心的正確性依賴「拆分不損失」，一旦每筆交易有固定成本，這個前提就崩了。**

### 定理 3（**121：為什麼「只買賣一次」不需要交易次數維度**）

*命題*：$121$ 的答案 $=\max_i \big(p_i - \min_{j<i} p_j\big)$，等價於把狀態機的買入邊權從 $f(i-1,0)-p_i$ 改成 $-p_i$。

*證明*。把 $f(i,1)$ 的轉移中的 $f(i-1,0)$ **強制設為 0**，意思是「買入之前沒有任何已實現利潤」⇒ 買入必定是第一筆交易 ✔。於是 $f(i,1)=\max_{j\le i}(-p_j) = -\min_{j\le i}p_j$，$f(i,0)=\max_{i}\big(p_i + f(i-1,1)\big)$ ✔。$\square$

**這說明「交易次數上限」不一定要開一維**——**上限為 1 時，用「切斷回流邊」就能表達。這是狀態機 DP 的常用簡化。**

### 定理 4（**188：$k \ge \lfloor n/2 \rfloor$ 時退化成無限次**）

*命題*：任何有正利潤的交易序列，交易筆數不超過 $\lfloor n/2 \rfloor$。因此當 $k \ge \lfloor n/2\rfloor$ 時，「至多 $k$ 次」的約束**恆不緊**，可直接套 122 的 $O(n)$ 解法。

*證明*。每筆交易佔用**至少兩個不同的日子**（買入日 $<$ 賣出日；同日買賣利潤為 0，可刪去而不減少總利潤）。不同交易的日子區間互不重疊（內部不重疊）⇒ 筆數 $\le \lfloor n/2\rfloor$ ✔。$\square$

**這條的實務價值極大**：188 的 $k$ 可以到 $10^9$，**不做這個判斷會直接 MLE**（開 $O(nk)$ 的表）✘。

**推論 4.1（「至多 $k$ 次」= 直接讀 $f(n-1,k,0)$）**：因為狀態機允許「什麼都不做」的自環，$f(i,j,\cdot)$ 已經涵蓋了「用了不到 $j$ 筆」的情形 ✔ ⇒ **不需要 $\max_{j'\le k}$**。**這與 5.3 定理 1 的「至多 vs 恰好」是同一個問題，但這裡答案更漂亮：狀態機的自環天生就吸收了較少次數的方案。**

**⚠ 前提**：這只在**「不交易」的利潤是單位元（0）且不會比交易更差**時成立。**若題目要求「恰好 $k$ 筆」，就必須把 $j$ 的初始化改成只有 $f(\cdot,0,\cdot)$ 有效、答案取 $f(n-1,k,0)$ 且不允許自環吸收** ✘——**兩種語意的程式碼幾乎一樣，但初始化不同。**

### 定理 5（**309：冷凍期為什麼是 $f(i-2,0)$**）

*命題*：賣出後冷凍一天時，$f(i,1) = \max\big(f(i-1,1),\ f(i-2,0) - p_i\big)$。

*證明*。要在第 $i$ 天買入，必須第 $i$ 天不在冷凍中 ⇒ 第 $i-1$ 天**沒有賣出** ⇒ 第 $i-1$ 天結束時的「未持有」狀態必須是「不是剛賣出來的」。

而 $f(i-2,0)$ 表示第 $i-2$ 天結束時未持有；從第 $i-2$ 天到第 $i-1$ 天若什麼都不做，第 $i-1$ 天仍是未持有且不在冷凍 ✔。**反過來，任何「第 $i$ 天可買入」的狀態都可以回溯到某個 $f(i-2,0)$**（第 $i-1$ 天必定無動作）✔。$\square$

**⚠ 這個寫法的隱含前提**：$f(i-2,0) \le f(i-1,0)$ 不一定成立，**所以不能偷懶寫成 $f(i-1,0)$**；反過來也**不能**因為「$f$ 對 $i$ 單調不減」就認為兩者可互換——$f(i,0)$ 確實對 $i$ 單調不減（多一天總可以不動），**但我們需要的是「排除剛賣出」這個語意，不是數值大小** ✔。

**更保險的寫法是三態**（自由 / 持有 / 冷凍），把語意直接寫進狀態，**不依賴任何 $i-2$ 的巧合** ✔——**初學者建議一律先寫三態版本，確認過了再壓縮。**

### 定理 6（狀態機 DP 的一般框架）

把本節六題抽象出來：

> 給定有限狀態集合 $S$、轉移關係 $\delta \subseteq S\times S$、以及邊權函數 $w_i(s\to s')$（可依時刻 $i$ 變化），求
> $$f(i,s') = \operatorname*{opt}_{(s,s')\in\delta}\big(f(i-1,s) + w_i(s\to s')\big).$$

*正確性*：與定理 1 完全相同的歸納——**只要「第 $i$ 步的可行動作僅由第 $i-1$ 步的狀態決定」（Markov 性），劃分就互斥窮盡** ✔。

*複雜度*：$O(n\cdot|\delta|)$，空間 $O(|S|)$（滾動）。

**這個框架的邊界在哪裡？**
- **$|S|$ 必須小**——若「身分」需要記住一個集合，那是 9 章狀壓 DP；
- **轉移必須只看前一步**——若要看前兩步，就把「前兩步」打包成一個狀態（7.4 的做法）；
- **$n$ 極大而 $\delta$ 固定** ⇒ **矩陣快速冪**把 $O(n|\delta|)$ 降到 $O(|S|^3\log n)$（6.3 會用到）。

## 時間與空間複雜度

| 題 | 時間 | 空間 |
| --- | --- | --- |
| 121 / 122 / 714 / 309 | $O(n)$ | $O(1)$ |
| 123 | $O(n)$（狀態數固定為 5 或 4） | $O(1)$ |
| 188（一般） | $O(nk)$ | $O(k)$（滾動掉 $i$） |
| 188（$k\ge\lfloor n/2\rfloor$） | $O(n)$ | $O(1)$ |

**滾動的正確性**：$f(i,\cdot)$ 只依賴 $f(i-1,\cdot)$ ⇒ 一維陣列即可。**但 $j$ 維度就地更新時要注意方向**（2.1 定理 2）：本節的轉移 $f(i,j,1)\leftarrow f(i-1,j-1,0)$ **跨 $j$ 讀取**，所以 **$j$ 必須遞減**，或用兩張表 ✔。

**309 的三態版本**空間 $O(1)$，但**必須用三個暫存變數同時更新**（讀到的都要是「昨天」的值）✔。

**$k$ 的上界壓縮**：`k = min(k, n / 2)`，**這一行同時解決 TLE 與 MLE** ✔。

## 與相似技巧的比較

- **與 1.1 打家劫舍**：打家劫舍其實是**只有兩個狀態（偷 / 不偷）的狀態機**——**本節是它的一般化。** 反過來看，能用「$f(i)$ 與 $f(i-1)$ 兩個變數」寫出來的題，都可以改寫成狀態機形式。
- **與 5.3 定理 4（1473 粉刷房子 III）**：那裡用狀態機取代「枚舉段起點」，本節用狀態機取代「枚舉買賣時點」——**同一個手法：把「歷史」壓縮成有限個身分。**
- **與貪心**：122 的貪心正確（定理 2），**但 714、309、188 都不能貪心。判準：每筆交易有固定成本或次數上限時，「局部正差」不再是可分解的** ✘。
- **與 7.4 合法子序列 DP**：那裡狀態要記「結尾的數值特徵」（公差、比例），狀態數與輸入有關；**本節的狀態數是常數。這是「狀態機 DP」與「一般多維 DP」的分界。**
- **與 6.3 / 矩陣快速冪**：轉移矩陣不隨 $i$ 變化時（本節因為 $\pm p_i$ 而會變，**所以不能用**），才能上矩陣快速冪。**這說明「邊權與時刻有關」是使用矩陣快速冪的攔路石。**
- **與 9 章狀壓 DP**：身分只能取有限個標籤 ⇒ 本節；身分是一個子集合 ⇒ 狀壓。

## 本節重點速查

- **核心**：狀態 $=$ **位置 $\times$ 身分**。$f(i,0)$ 未持有、$f(i,1)$ 持有；買入 $-p_i$、賣出 $+p_i$。
- **初始化**：$f(0,0)=0$、$f(0,1)=-p_0$；**「持有」在開始前是 $-\infty$，不是 0** ✘。
- **定理 1**：正確性靠「第 $i$ 天只可能做一個動作」的互斥窮盡劃分；前提是**每天一動作、利潤可加**。
- **定理 2（122）**：$\sum\max(0,p_i-p_{i-1})$，用**望遠鏡和 + 區間不重疊**證明兩個方向。**加手續費後失效**（反例 $[1,3,2,4]$、$\mathit{fee}=2$：貪心 0，最優 1）。
- **定理 3（121）**：只買一次 = **切斷買入邊的回流**（$f(i-1,0)\to 0$），不必開次數維。
- **定理 4（188）**：**$k \ge \lfloor n/2\rfloor$ 就退化成 122**，因為每筆交易佔至少兩天。**`k = min(k, n/2)` 是必寫的一行**（否則 $k=10^9$ 直接 MLE）。「至多 $k$ 次」由自環自動吸收，**不必取 $\max_{j\le k}$。**
- **定理 5（309）**：買入讀 $f(i-2,0)$；**更保險是寫三態（自由 / 持有 / 冷凍），語意直接進狀態。**
- **定理 6**：一般框架 $f(i,s')=\operatorname{opt}_{(s,s')\in\delta}(f(i-1,s)+w_i(s\to s'))$，$O(n|\delta|)$；**$|S|$ 要小、只看前一步**。
- **滾動陷阱**：188 的 $j$ 維度就地更新時**必須遞減**（跨 $j$ 讀 $j-1$），同 2.1 定理 2。
