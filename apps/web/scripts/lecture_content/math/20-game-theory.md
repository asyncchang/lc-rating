## 這個技術解決什麼問題

兩人輪流操作、雙方都採取最優策略時，判斷先手勝負。把每個局面標成「必勝態」或「必敗態」，就能把博弈化成一個在狀態圖上的遞推。

## 狀態／資料結構定義

`win[s]` 表示輪到某方面對局面 `s` 時是否必勝。狀態通常是剩餘的石子數、可用的操作集合，或多堆遊戲中各堆的大小。Nim 類問題則用異或和作為單一狀態量。

## 不變量或正確性證明

兩條定義互相遞迴：

- 局面 `s` 是**必勝態**，當且僅當存在一個合法走法 使對手落入必敗態。
- 局面 `s` 是**必敗態**，當且僅當所有合法走法 都讓對手進入必勝態（含無路可走）。

正確性由對狀態圖的深度歸納給出：終止局面無合法走法，依定義為必敗態。設所有後繼狀態都已正確標記，若某個後繼為必敗態，當前方只要走過去即可迫使對手輸，故當前為必勝；若所有後繼皆為必勝，則無論怎麼走對手都能贏，故當前必敗。要求狀態圖無環，否則遞推無定義（需另行處理平局或用更精細的分析）。

Nim 的 Sprague-Grundy 定理：多堆遊戲的必敗態當且僅當各堆大小的異或和為 0。

證明兩個方向：若異或和為 0，任何一步只改動一堆，必使異或和變為非 0（因為改變單一項必改變異或結果），故對手總能接到非 0 局面；若異或和為 `x ≠ 0`，設其最高位為第 `b` 位，必存在某堆該位為 1，把該堆調整為「它與 `x` 的異或值」（此值嚴格小於原值，故是合法走法），即可使總異或和歸零。因此異或和為 0 的局面所有走法 都通往非 0，而非 0 局面必存在通往 0 的走法——恰好符合必敗與必勝的定義。

## 時間與空間複雜度

樸素狀態遞推為 $O(狀態數 \times 每狀態的走法數)$。Nim 用異或和只需 $O(n)$ 掃過各堆，空間 $O(1)$。SG 函數需對每個狀態求後繼集合的 mex，成本較高。

## 與相似技巧的比較

單堆或狀態少時直接 DP 標記勝負；多堆獨立遊戲用 SG 定理拆解後異或；若雙方目標不是單純輸贏而是最大化分數，則屬於極小化極大（minimax）而非勝負博弈，需改記錄分差。

## 本節重點速查

有一個後繼是必敗就必勝；全部後繼必勝才必敗；Nim 看異或和是否為 0；狀態圖必須無環。
