## 這個技術解決什麼問題

判斷單一整數 `n` 是否為質數。試除到 `n - 1` 是 $O(n)$，對 $10^9$ 等級的輸入不可行；根號試除把成本壓到 $O(\sqrt{n})$，是單次查詢的標準做法。

## 狀態／資料結構定義

只需要一個迴圈變數 `i`，從 2 遞增到 $\lfloor\sqrt{n}\rfloor$。判斷條件是 `n % i == 0`；用 `i * i <= n` 代替 `i <= sqrt(n)`，避免浮點誤差。

## 不變量或正確性證明

不變量：迴圈進行到 `i` 時，`n` 沒有任何落在 `[2, i)` 的因數。

只試到根號就足夠的理由：若 `n` 是合數，可寫成 `n = a * b` 且 `a, b > 1`。兩者不可能同時大於 $\sqrt{n}$，否則乘積超過 `n`；故必有一個因數不超過 $\sqrt{n}$，會在迴圈內被找到。反之迴圈跑完仍無因數，表示不存在不超過 $\sqrt{n}$ 的因數，由上述論證也就不存在任何真因數，`n` 為質數。

## 時間與空間複雜度

最多試除 $\sqrt{n}$ 次，時間 $O(\sqrt{n})$，空間 $O(1)$。若要判斷 $[1, n]$ 中每個數，逐個試除是 $O(n\sqrt{n})$，此時應改用篩法。

## C++17 模板

```cpp
bool isPrime(long long n) {
  if (n < 2) { return false; }
  for (long long i = 2; i * i <= n; ++i) {   // 用乘法避免 sqrt 的浮點誤差
    if (n % i == 0) { return false; }
  }
  return true;
}
```

## 常見錯誤與邊界條件

漏掉 `n < 2` 的判斷（0、1 與負數都不是質數）；用 `i <= sqrt(n)` 而遇到浮點捨入誤判；`i * i` 在 `int` 下溢位，需用 `long long`；2 是唯一的偶質數，若加了「先排除偶數」的優化就要單獨放行 2。

## 與相似技巧的比較

單次查詢用根號試除；要反覆查詢一個範圍內的數就預處理埃氏篩或線性篩，把單次查詢降到 $O(1)$。若 `n` 大到 $10^{18}$，根號試除也不夠，需改用 Miller-Rabin 機率性判定。

## 本節重點速查

只試到根號就夠；用 `i * i <= n` 不用 `sqrt`；先擋掉小於 2；大範圍多次查詢改用篩法。
