## 這個技術解決什麼問題

一次求出 `[0, n]` 範圍內所有數的質數狀態，讓後續查詢變成 $O(1)$。當題目要反覆判斷質數、或需要列舉範圍內全部質數時，逐個根號試除的 $O(n\sqrt{n})$ 太慢。

## 狀態／資料結構定義

`is_prime` 是長度 `n + 1` 的布林陣列，初始除 0 與 1 外全為真。埃氏篩從每個質數 `p` 出發，把 `p * p`、`p * p + p`、…標記為合數。線性篩另外維護一個 `primes` 陣列與每個數的最小質因數。

## 不變量或正確性證明

埃氏篩的不變量：外層走到 `p` 時，所有小於 `p` 且仍標記為真的數都是質數。

歸納說明：初始所有數為真。當外層抵達 `p` 且 `is_prime[p]` 仍為真，表示 `p` 沒有被任何更小的質數標記過，即 `p` 沒有小於自己的質因數，故 `p` 是質數。接著把 `p` 的所有倍數標記為合數，維持了不變量。

從 `p * p` 開始標記是安全的：任何 `p * k` 且 `k < p` 的合數，都含有一個小於 `p` 的質因數，早在處理那個更小的質數時就已被標記。

線性篩的關鍵不變量：每個合數只被它的**最小**質因數篩一次。內層在 `p` 整除 `i` 時立即中斷，確保 `i * p` 的最小質因數恆為 `p`，因此不會重複標記，總成本降為線性。

## 時間與空間複雜度

埃氏篩為 $O(n \log \log n)$——調和級數 $\sum_{p \le n} n/p$ 的量級；線性篩為 $O(n)$。兩者空間皆為 $O(n)$。$n = 10^7$ 時兩者都可在數十毫秒內完成。

## 常見錯誤與邊界條件

- 忘記把 0 與 1 標記為非質數。
- 內層從 `2 * p` 開始（正確但多做無用功）。
- `p * p` 在 `int` 下溢位，需用 `long long` 或把外層條件寫成 `p <= n / p`。
- 線性篩漏掉 `if (i % p == 0) break;` 而退化成埃氏篩。
- 陣列開成 `n` 而非 `n + 1` 造成越界。

## 與相似技巧的比較

單次判斷用根號試除即可，不必付出 $O(n)$ 空間；線性篩比埃氏篩快一個 $\log \log n$ 因子，且能順帶得到每個數的最小質因數，適合需要大量質因數分解的題目；若只關心某個大區間 `[L, R]` 而 `R` 很大，改用區間篩。

## 本節重點速查

- 從 `p * p` 開始標記
- `is_prime[p]` 為真即 `p` 是質數
- 線性篩靠 `i % p == 0` 就中斷
- 記得排除 0 與 1。
