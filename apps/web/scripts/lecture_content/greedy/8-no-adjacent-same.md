## 這個技術解決什麼問題

把一堆同類元素重新排列，使相同的元素不相鄰；或在有冷卻時間的限制下排程任務，求最短總時間。代表題是「重構字串」與「任務排程器」。

## 狀態／資料結構定義

先統計每種元素的出現次數。構造時用大根堆每次取出剩餘最多的兩種交替放置；計算最短時間則只需最大次數 `maxCount` 與「達到該次數的種類數」`maxKinds`。

## 不變量或正確性證明

可行性判據：長度為 `n` 的序列能重排成相鄰不同，當且僅當出現最多的元素次數 $c_{\max} \le \lceil n/2 \rceil$。

必要性：把最多的那種元素放進序列，任兩個之間至少要隔一個別的元素，故若有 `c` 個，至少需要 `c - 1` 個間隔，總長至少 `2c - 1`，即 $c \le \lceil n/2 \rceil$。

充分性用構造證明：先把出現最多的元素依序放在下標 0, 2, 4, …（偶數位），放完再從剩下的位置繼續，其餘元素依次填入。由於同種元素被放在間隔至少 2 的位置，或跨越偶數位與奇數位的邊界時恰好接續，故不會相鄰。

任務排程的最短時間公式為

$$\max\left(n,\; (c_{\max}-1)(k+1) + m\right)$$

其中 `k` 為冷卻時間、`m` 為達到最大次數的種類數。推導：把出現最多的元素當作骨架，切成 $c_{\max}-1$ 個長度為 `k+1` 的區塊，最後再補上 `m` 個並列的最高頻元素。若其他任務多到填滿所有空檔仍有剩，則不會有閒置，總時間就是任務總數 `n`——取兩者較大者即涵蓋兩種情形。

## 逐步演算法

統計次數；判斷可行性；構造時用大根堆每輪取出兩種不同的元素各放一個，用完再放回堆中；或用「填偶數位再填奇數位」的直接構造。

## C++17 模板

```cpp
// 任務排程器：相同任務之間至少間隔 k，求最短總時間。
int leastInterval(vector<char>& tasks, int k) {
  array<int, 26> count{};
  for (char c : tasks) { ++count[c - 'A']; }

  const int maxCount = *max_element(count.begin(), count.end());
  const int maxKinds = std::count(count.begin(), count.end(), maxCount);

  const int framed = (maxCount - 1) * (k + 1) + maxKinds;
  return max(static_cast<int>(tasks.size()), framed);   // 空檔被填滿時就是 n
}
```

## 常見錯誤與邊界條件

忘記與任務總數取 `max`，在任務種類很多時算出偏小的結果；`maxKinds` 只算成 1；冷卻時間 `k` 為 0 時答案就是 `n`（公式自然涵蓋）；構造題未先判可行性就直接輸出；堆中元素次數歸零仍放回。

## 與相似技巧的比較

只問「最短時間」時有封閉公式，$O(n)$ 即可；要真的輸出一組排列時才需要堆的構造法，成本 $O(n \log \Sigma)$。若限制不是「相鄰不同」而是更複雜的相容關係，則屬圖著色問題，一般不可貪心。

## 本節重點速查

可行條件是 $c_{\max} \le \lceil n/2 \rceil$；排程公式別忘了與 `n` 取 `max`；`maxKinds` 要算對；構造用大根堆交替放。

## 時間與空間複雜度

統計次數 $O(n)$；只求最短時間時為 $O(n)$ 時間、$O(\Sigma)$ 空間。若要實際輸出一組排列，用大根堆逐個放置為 $O(n \log \Sigma)$。
