## 這個技術解決什麼問題

當若干正數的總和固定時，判斷它們該平均分配還是走極端。均值不等式給出答案：和固定時越平均乘積越大，越極端乘積越小。

## 狀態／資料結構定義

多數題目只需算出「平均值」與餘數，再構造出最平均的分配。例如把 `n` 拆成 `k` 份時，`n / k` 份取商、餘下 `n % k` 份各多一。

## 不變量或正確性證明

算術幾何平均不等式（AM-GM）：對非負實數 $x_1, \ldots, x_n$，

$$\frac{x_1 + \cdots + x_n}{n} \ge \sqrt[n]{x_1 \cdots x_n}$$

等號成立當且僅當所有 $x_i$ 相等。

在整數情境下更常用的是它的離散推論：若 $x + y$ 固定，則 $xy$ 在 $|x-y|$ 最小時最大。證明很直接——設 $x + y = s$，則 $xy = x(s-x) = -\left(x - \frac{s}{2}\right)^2 + \frac{s^2}{4}$，這是開口向下的拋物線，在 $x = s/2$ 處取極大，且離對稱軸越遠值越小。整數時取最接近 $s/2$ 的兩個值。

推廣到多個數：若某兩個數相差超過 1，把較大者減一、較小者加一，總和不變而乘積嚴格增加（由上述二次式論證），故最優配置中任兩數相差不超過 1——這唯一對應「盡量平均」的分法。

反向的應用同樣重要：要讓乘積**最小**，就把值全部集中到極端（一個取最大、其餘取最小），因為那是離平均最遠的配置。

## 逐步演算法

確認總和固定；若求乘積最大就平均分配（用商與餘數構造）；若求最小就走極端；代入計算，必要時取模。

## C++17 模板

```cpp
// 把 n 拆成 k 個正整數，使乘積最大（盡量平均）。
long long maxProductSplit(long long n, long long k, long long mod) {
  const long long base = n / k, remainder = n % k;
  // remainder 份是 base + 1，其餘 k - remainder 份是 base
  return power(base + 1, remainder, mod) * power(base, k - remainder, mod) % mod;
}
```

## 常見錯誤與邊界條件

把「和固定求乘積最大」與「積固定求和最小」搞混（兩者都由 AM-GM 導出但構造不同）；餘數分配錯誤（應有 `n % k` 份多一）；`base` 為 0 時（`k > n`）無法拆成正整數，需特判；取模前先比較大小而失效。

## 與相似技巧的比較

排序不等式管的是「怎麼配對」，均值不等式管的是「怎麼分配總量」，兩者常一起出現在數學貪心題中。若分配還有上下界限制，均值不等式只給方向，實際構造需再配合貪心或二分。

## 本節重點速查

和固定時越平均乘積越大；任兩份相差不超過 1；求最小就走極端；餘數決定有幾份要多一。

## 時間與空間複雜度

直接由商與餘數構造，$O(1)$；若需取模冪則為 $O(\log k)$。空間 $O(1)$。
