## 這個技術解決什麼問題

把序列切成若干段，每段滿足某條件，目標是段數最多或切割代價最小。代表題是「劃分字母區間」「平衡字串分割」。

## 狀態／資料結構定義

維護當前段的起點與一個「該段何時可以結束」的判據：字母區間題用「段內所有字元的最後出現位置的最大值」，平衡字串用計數器歸零。

## 不變量或正確性證明

不變量：每次切割發生時，`[start, i]` 是「以 `start` 為起點的**最短**合法段」。

貪心取最短段為何能使段數最多：設某最優解的第一段為 `[0, r]`，而貪心的第一段為 `[0, g]` 且 `g <= r`（因為貪心一旦合法就立刻切）。把最優解的第一段縮短為 `[0, g]`，剩下的 `[g+1, r]` 併入第二段——需要確認這樣仍合法。

以劃分字母區間為例，合法性條件是「同一字母不可跨段」。貪心在 `i` 等於段內所有字元最後出現位置的最大值時才切，因此 `[0, g]` 內的字元都不會出現在 `g` 之後，切開安全；而 `[g+1, r]` 併入下一段只是讓該段變長，不會讓任何字母被拆開。故替換後段數不減。逐段重複此論證，可把最優解轉成貪心解。

這裡的關鍵前提是**合法性對「延長」封閉**——把一段變長不會使它變得不合法。若條件反過來（越短越合法），貪心方向就要顛倒。

## 逐步演算法

預處理判據所需資訊（例如每個字元的最後出現位置）；從左掃描並更新當前段的結束門檻；一旦掃到門檻就切一刀、記錄段長、把起點移到下一格。

## C++17 模板

```cpp
// 劃分字母區間：同一字母只能出現在同一段。
vector<int> partitionLabels(string s) {
  array<int, 26> last{};
  for (int i = 0; i < static_cast<int>(s.size()); ++i) { last[s[i] - 'a'] = i; }

  vector<int> result;
  int start = 0, end = 0;
  for (int i = 0; i < static_cast<int>(s.size()); ++i) {
    end = max(end, last[s[i] - 'a']);      // 這段至少要延伸到這裡
    if (i == end) {                        // 門檻到了，可以切
      result.push_back(i - start + 1);
      start = i + 1;
    }
  }
  return result;
}
```

## 時間與空間複雜度

預處理與掃描各一次，時間 $O(n)$，空間 $O(\Sigma)$ 或 $O(1)$。

## 常見錯誤與邊界條件

門檻更新寫在切割判斷之後；切完忘記重置起點；段長算成 `i - start`（正確為 `i - start + 1`）；條件其實是「越短越合法」卻仍用最短段貪心；最後一段未被切出（若門檻邏輯正確則會自然切出，不需特判）。

## 與相似技巧的比較

若每段的代價不是常數而依段內容變化，且要最小化總代價，貪心通常失效，須用 DP（`f[i]` 為前 `i` 個字元的最小代價）；分組迴圈處理的是「條件已明確給出分界」的情形，本節則是要自行推導最早可切點。

## 本節重點速查

貪心切最短合法段；先更新門檻再判斷；合法性須對延長封閉；段長是 `i - start + 1`。
