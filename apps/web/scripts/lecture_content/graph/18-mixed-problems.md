## 這個技術解決什麼問題

本節是圖論題單的綜合練習區，題目不預先告知該用哪個演算法。真正要訓練的能力是「從題面反推模型」：先判斷這是哪一類圖問題，再挑出前面各節學過的工具。

## 辨識題型的訊號

題目沒有明說是圖，卻出現「連通」「依賴」「最少步數」「配對」「刪掉之後會不會斷」這類字眼；或者資料本身是關係集合（配對、指向、相鄰）。看到這些訊號，第一步都是問自己：節點是什麼、邊是什麼。

## 核心想法與直覺

建模有三個固定問句，順序不能顛倒。第一，節點是什麼——是原始物件，還是「物件加上額外狀態」（分層圖）？第二，邊是什麼、有沒有方向、有沒有權重？第三，要求的量落在哪個範疇——遍歷、最短路、連通性、排序、還是分配？答出這三題，演算法幾乎就唯一確定了。

## 狀態／資料結構定義

依判斷結果選用：遍歷與連通用 `visited` 加鄰接表或並查集；最短路用 `dist` 加佇列或堆；依賴排序用 `indeg` 加佇列；分配問題用殘量網路。狀態需要附加資訊時（剩餘額度、已訪問集合、奇偶性），就把它併進節點編號成為新的一維。

## 不變量或正確性證明

本節不引入新的不變量，而是提醒每個工具的成立前提——選錯工具的原因幾乎都是前提沒檢查：

- BFS 的「第一次到達即最短」需要所有邊權相同。
- Dijkstra 的「出堆即定案」需要邊權非負。
- 拓撲 DP 的「出隊即定型」需要圖無環。
- Kruskal 的貪心需要割性質，只適用於無向圖的生成樹。
- 二分染色的「衝突即奇環」需要圖無向。

套用前先確認前提成立，是本節最該養成的習慣。

## 逐步演算法

讀題後先寫下節點與邊的定義；估算節點數與邊數，據此排除複雜度不可行的方案；比對下方對照表選定演算法；實作後用極小案例（單點、無邊、自環、不連通）驗證。

## C++17 模板

本節沿用前面各節的模板，選擇依據整理如下：

| 題目要的東西           | 前提     | 對應工具            | 複雜度        |
| ---------------------- | -------- | ------------------- | ------------- |
| 走遍、連通塊、子樹統計 | 無       | DFS / BFS           | $O(n+m)$      |
| 最少步數               | 邊權相同 | BFS                 | $O(n+m)$      |
| 最短距離               | 邊權非負 | Dijkstra            | $O(m \log m)$ |
| 最短距離               | 有負權   | SPFA / Bellman-Ford | $O(nm)$       |
| 任意兩點距離           | `n` 很小 | Floyd               | $O(n^3)$      |
| 合法執行順序           | 有向無環 | 拓撲排序            | $O(n+m)$      |
| 最小連通成本           | 無向帶權 | Kruskal / Prim      | $O(m \log m)$ |
| 只有一條出邊           | 出度為 1 | 基環樹拓撲剝除      | $O(n)$        |
| 分兩組互不衝突         | 無向     | 二分染色            | $O(n+m)$      |
| 互相可達的群組         | 有向     | Tarjan 縮點         | $O(n+m)$      |
| 關鍵邊、關鍵點         | 無向     | 橋 / 割點           | $O(n+m)$      |
| 配對、容量分配         | 有容量   | Dinic 最大流        | $O(n^2m)$     |

## 時間與空間複雜度

先用資料範圍反推可接受的複雜度，再選演算法：`n` 在 $10^5$ 以上通常只能是 $O(n+m)$ 或 $O(m \log m)$；`n` 在數百時 $O(n^3)$ 的 Floyd 可行；`n` 在 20 上下往往是位元遮罩而非傳統圖論。

## 常見錯誤與邊界條件

- 沒檢查前提就套模板（負權用 Dijkstra、有環用拓撲 DP 是最常見的兩種）。
- 忽略圖不連通。
- 忘記節點編號從 1 或從 0 開始的差異。
- 無向圖漏加反向邊。
- 把「走遍所有邊」與「走遍所有點」搞混。
- 小案例（`n == 1`、沒有邊、有自環或重邊）未驗證。

## 與相似技巧的比較

當題目的狀態帶有額外維度時，圖論與 DP 的界線會變模糊：分層圖最短路本質是 DP，拓撲序上 DP 本質是圖。判準是「轉移是否成環」——無環用 DP 遞推，有環且求最值就靠 Dijkstra 這類定案式演算法。

## 本節重點速查

- 先定義節點與邊，再選工具
- 用資料範圍反推複雜度
- 每個演算法的前提都要先驗證
- 小案例一定要試。
