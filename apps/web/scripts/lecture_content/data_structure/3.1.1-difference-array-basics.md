## 這個技術解決什麼問題

前綴和（2.1）處理「多次查詢區間和、不修改」。差分處理**完全對偶**的情形：**多次區間整體加值，最後只查一次結果。**

暴力是每筆操作都把區間逐格加一遍：$m$ 筆操作、區間長 $L$，總計 $O(mL)$。1109（航班預訂統計）有 $m = 2\times10^4$ 筆、$n = 2\times10^4$ 個航班，最壞 $4\times10^8$，超時。

差分把每筆區間操作攤成**兩次單點修改** $O(1)$，最後做一次前綴和 $O(n)$ 還原，總計 $O(n + m)$。

這個技巧的內容也是一句話：**「對一段整體加 $v$」等價於「在左端點記 $+v$、在右端點後一格記 $-v$」。** 微積分的說法是：階梯函數的導數是兩個脈衝。很多題目表面上沒有「區間加值」，但只要能改寫成「某個量在 $l$ 開始生效、在 $r$ 之後失效」，就是差分——1854（人口最多的年份）的出生 $+1$、死亡 $-1$ 就是最典型的例子。

## 狀態／資料結構定義

**定義（差分陣列）。** 對長度 $n$ 的陣列 $a$，令 $a_{-1} = 0$，
$$d_i = a_i - a_{i-1}, \qquad 0 \le i < n .$$

**還原（前綴和）：** $a_i = \sum_{t \le i} d_t$。差分與前綴和互為逆運算。

**區間加值 $[l, r] \mathrel{+}= v$：**
$$d_l \mathrel{+}= v, \qquad d_{r+1} \mathrel{-}= v .$$

**陣列必須開 $n+1$ 格**（下標 $0 \dots n$），因為 $r$ 可以是 $n-1$，此時 $d_{r+1} = d_n$ 要有地方放。$d_n$ 只是個垃圾桶，還原時不讀它——**但少開這一格就得寫 `if (r + 1 < n)` 特判，那是 bug 溫床，和 2.1 的哨兵一樣的道理，只是方向相反。**

**兩種常見的座標約定，務必先確認題目是哪一種：**

| 語意 | 差分寫法 |
| --- | --- |
| 閉區間 $[l, r]$（1094 上車 $l$、下車 $r$ 仍在車上） | `d[l] += v; d[r+1] -= v;` |
| 半開區間 $[l, r)$（1094 實際語意：`to` 站已下車；1854 死亡年份不計） | `d[l] += v; d[r] -= v;` |

**這兩行只差一格，錯了會在端點處全盤皆錯。** 判準是問自己：「$r$ 這一格算不算在內？」

**值域很大或非整數時**（座標到 $10^9$、時間是浮點），不能直接開陣列，要改用 `map<key, delta>` 或「事件排序掃描」——那是 3.1.2 的內容。

## 不變量或正確性證明

**主不變量。** 在任意一串區間加值操作之後，恆有
$$a_i \;=\; \sum_{t=0}^{i} d_t \qquad \text{對所有 } 0 \le i < n .$$

*證明（對操作次數歸納）。*

**基底**：初始 $a \equiv 0$、$d \equiv 0$，等式成立。

**歸納步**：設不變量在前 $k$ 筆操作後成立。第 $k+1$ 筆是 $[l,r] \mathrel{+}= v$，它把真實陣列改成 $a_i' = a_i + v\cdot[\,l \le i \le r\,]$，把差分陣列改成 $d_l' = d_l + v$、$d_{r+1}' = d_{r+1} - v$，其餘不變。於是
$$\sum_{t \le i} d_t' \;=\; \sum_{t \le i} d_t \;+\; v\cdot[\,l \le i\,] \;-\; v\cdot[\,r+1 \le i\,] \;=\; a_i + v\cdot[\,l \le i \le r\,] \;=\; a_i' .$$
中間那步用到 $[\,l\le i\,] - [\,r+1 \le i\,] = [\,l \le i \le r\,]$（當 $l \le r$）。$\square$

**這條論證點名了四個前提，每一個對應一種會踩雷的題型。**

1. **操作必須可疊加（線性）。** 歸納步只用到「$a_i$ 增加 $v$」這件事的**可加性**。若操作改成「區間**賦值**為 $v$」（覆蓋而非累加），$a_i' = v$ 與舊值無關，上式徹底不成立——**區間賦值必須用帶懶標記的線段樹（9.4），差分無能為力。** 這是最重要的一條分界。
2. **值的運算必須有逆元。** 需要「$-v$」來抵銷。區間**乘**法可以用「差分於對數空間」或「商差分」($d_i = a_i / a_{i-1}$) 處理，但一旦出現 0 就崩潰。
3. **操作與查詢必須分階段。** 不變量本身在任何時刻都成立，所以「隨時想知道 $a_i$」在理論上沒問題——**問題是每次還原要 $O(n)$。** 若操作與查詢交錯 $q$ 次，總成本 $O(nq)$，還不如樹狀陣列的 $O((n+q)\log n)$。**判準不是「能不能」，而是「划不划算」。**
4. **$l \le r$。** 空區間（$l > r$）會讓那個恆等式反號，變成區間 $[r+1, l-1]$ 減 $v$。多數題目保證 $l \le r$，但自己構造區間時（例如 798 那種「把每個位置的可得分輪調量轉成區間」）很容易生出空區間或跨越邊界的環狀區間，**必須自己擋掉或拆成兩段。**

**推論（差分讀出的是「覆蓋次數」）。** 若每筆操作都是 $+1$，則還原後的 $a_i$ 就是「有幾個區間覆蓋位置 $i$」。$\max_i a_i$ 便是最大重疊數——1094（拼車）、1854（人口最多的年份）、2848（統計汽車上的所有整數點）全是這一句話的直接應用。

**3355（零陣列變換 I）的可行性判準。** 給定 nums 與若干查詢區間，每個查詢可對區間內**任意子集**各減 1，問能否讓 nums 全變 0。

*宣稱*：可行 $\iff$ 對每個 $i$，$\mathrm{cover}_i \ge \mathrm{nums}_i$，其中 $\mathrm{cover}_i$ 是覆蓋 $i$ 的查詢數。

*必要性*：位置 $i$ 每個查詢最多讓它減 1，故總減量 $\le \mathrm{cover}_i$。
*充分性*：各位置的減量**互相獨立**（每個查詢可自由選子集，位置之間沒有耦合），所以只要每個位置各自的預算夠，就各自減足即可。$\square$

**充分性依賴「可任選子集」這個前提。** 若題目改成「必須整段一起減」（3356 零陣列變換 II 的部分變體、或要求每個查詢減固定量），位置之間就耦合了，這條判準立刻失效，得改用貪心 + 差分或二分答案。**同一個差分陣列，判準卻不同——差別在題目給的自由度。**

## 時間與空間複雜度

**建構**：$m$ 筆操作各 $O(1)$，共 $O(m)$。**還原**：一次前綴和 $O(n)$。**總計 $O(n + m)$ 時間、$O(n)$ 空間。**

與暴力 $O(mL)$ 的落差：1109 從 $4\times10^8$ 降到 $4\times10^4$。

**還原可以原地做**：`for (int i = 1; i < n; ++i) d[i] += d[i-1];` 之後 `d` 就是答案，不需額外陣列，$O(1)$ 額外空間。

**若值域是座標而非下標**（1854 的年份 $1950 \dots 2050$、2848 的座標 $1 \dots 100$），空間是 $O(V)$ 而非 $O(n)$。$V$ 大到開不下時（$10^9$）改用 `map`，時間變 $O(m\log m + m)$、空間 $O(m)$——**代價是一個 $\log$ 與很差的快取表現，但把空間從值域規模降到操作規模。** 見 3.1.2。

**交錯查詢的成本對照**（決定選型的關鍵表）：

| 情境 | 差分陣列 | 樹狀陣列（9.1） | 懶標記線段樹（9.4） |
| --- | --- | --- | --- |
| 區間加、最後一次全查 | $O(n+m)$ ✔ | $O((n+m)\log n)$ | $O((n+m)\log n)$ |
| 區間加、交錯單點查 $q$ 次 | $O(nq)$ ✘ | $O((m+q)\log n)$ ✔ | $O((m+q)\log n)$ |
| 區間加、交錯區間和查詢 | ✘ | 需兩個 BIT | $O((m+q)\log n)$ ✔ |
| 區間**賦值** | ✘ 不成立 | ✘ | $O((m+q)\log n)$ ✔ |

## 與相似技巧的比較

- **與 2.1 前綴和**：嚴格互逆。**前綴和 = 先修改完、多次查詢區間和；差分 = 多次修改區間、最後查詢。** 兩者都要求「修改與查詢分階段」，代價與收益完全鏡像。
- **與 3.2 二維差分**：同一套思路，區間加值變成矩形加值，兩個端點標記變成**四個角落標記**（容斥）。
- **與 3.1.2 事件掃描**：當座標稀疏或需要「合併區間」「找空檔」而非「逐點計數」時，差分陣列開不下，改成「端點事件 + 排序 + 掃描」。**本質完全相同——事件掃描就是把差分陣列的非零位置抽出來排序。**
- **與樹狀陣列（9.1）**：樹狀陣列是「差分 + 可修改」。實際上「區間加、單點查」的標準做法就是**對差分陣列建樹狀陣列**——兩次單點修改、一次前綴和查詢。**認出這一點，9.1 的那個技巧就不用背了。**
- **與懶標記線段樹（9.4）**：懶標記可以看成「掛在樹節點上的差分」，把 $O(n)$ 個標記壓成 $O(\log n)$ 個。差分陣列是它在「不需中途查詢」時的退化版。
- **與滑動視窗**：若操作區間長度固定且左端點單調，滑動視窗也能 $O(n)$ 完成，且不需額外陣列。**但區間長度不一或順序任意時，只有差分能做。**

## 本節重點速查

$d_i = a_i - a_{i-1}$（$a_{-1}=0$）；還原 $a_i = \sum_{t\le i} d_t$。**差分與前綴和互逆。**
區間加值 $[l,r] \mathrel{+}= v$ ⇒ `d[l] += v; d[r+1] -= v;`。**陣列開 $n+1$ 格**，省掉 `r+1 < n` 的特判。
**先確認閉區間還是半開區間**（`d[r+1]` vs `d[r]`），差一格就整題錯。
不變量：任意操作序列後 $a_i = \sum_{t\le i} d_t$，用歸納 + $[l\le i]-[r{+}1\le i]=[l\le i\le r]$ 證。
四個前提：**操作可疊加**（區間賦值不行，要線段樹）、**有逆元**、**修改與查詢分階段**（交錯就換樹狀陣列）、**$l \le r$**。
全部 $+1$ 時，還原結果就是「覆蓋次數」；$\max$ 即最大重疊數（1094、1854、2848）。
還原可原地做，$O(1)$ 額外空間；總計 $O(n+m)$。
座標稀疏 ⇒ `map` 或事件掃描（3.1.2）；要中途查詢 ⇒ 樹狀陣列（9.1）。
