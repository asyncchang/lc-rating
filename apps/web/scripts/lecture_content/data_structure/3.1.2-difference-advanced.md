## 這個技術解決什麼問題

3.1.1 的差分陣列有兩個硬限制：**座標必須密集**（要開得下陣列），以及**問的必須是「每一格的值」**。本節處理突破這兩點之後的三類題目。

**一、座標稀疏或非整數 ⇒ 事件掃描（掃描線）。** 區間端點在 $[0, 10^9]$ 或是浮點時間，陣列開不下。做法是只保留差分陣列的**非零位置**：把每個區間拆成兩個事件 $(l, +v)$、$(r{+}1, -v)$，排序後掃描並累加。$O(n\log n)$ 時間、$O(n)$ 空間，與值域無關。**事件掃描不是新演算法，它就是差分陣列的稀疏表示。**

**二、問的是區間結構而非逐格數值 ⇒ 合併區間家族。** 56（合併區間）、57（插入區間）、759（員工空閒時間）要的是合併後的區間列表、空檔位置，不是覆蓋次數。這類題排序後線性掃描即可，不需要真的做差分。

**三、差分的軸不是原陣列的下標，而是「答案的候選值」。** 這是本節最值得學的一招。798（得分最高的最小輪調）對**輪調量 $k$** 做差分；1674（使陣列互補的最少操作次數）對**目標和 $T$** 做差分；2528 對**電廠位置**做差分。共同形態是：*每個輸入元素會讓某一段候選答案變好（或變壞）固定的量*——那就在答案軸上做區間加值，最後掃一遍取最佳。**辨識訊號：「對每個候選答案都要算一次代價，而每個元素對代價的貢獻是分段常數」。**

## 狀態／資料結構定義

**事件掃描。**
- 事件列表 `vector<pair<Key, Delta>> ev`，`Key` 是座標（`int`/`long long`/`double`），`Delta` 是增量。
- 區間 $[l, r]$ 加 $v$ ⇒ `ev.push_back({l, v}); ev.push_back({r + 1, -v});`（閉區間、整數座標）。
- 排序後掃描，維護 `cur`（當前覆蓋值）與 `prev`（上一個事件座標）；區段 $[\texttt{prev}, \texttt{key})$ 上的值恆為 `cur`。
- **同一座標的多個事件必須一次全部處理完再取值**，否則會讀到中間狀態。標準寫法是用 `while (j < ev.size() && ev[j].first == key)` 把同座標的批次吃完。

用 `std::map<Key, Delta>` 也可以（自動排序、自動合併同座標），代價是 $O(\log n)$ 常數與差得多的快取表現。**離線（所有區間一次給齊）就用 vector + sort；線上（邊插入邊查詢）才用 map。**

**合併區間。** 排序後只需一個「當前累積區間」$[L, R]$，不需任何額外容器。

**答案軸差分。** 差分陣列的下標不是 $0..n-1$，而是候選答案的值域 $0..V$。**必須先確認 $V$ 夠小**（1674 的 $T \le 2\cdot\mathrm{limit} \le 2\times10^5$、798 的 $k < n$），否則要改事件掃描。

## 不變量或正確性證明

**引理 1（合併區間：按左端點排序後單向掃描是正確的）。**

設區間已按左端點遞增排序（左端點相同時右端點任意）。掃描時維護當前累積區間 $[L, R]$。宣稱：若第 $i$ 個區間滿足 $l_i > R$，則**其後所有區間都與 $[L,R]$ 不相交**，故 $[L,R]$ 可以安全輸出、不會再被擴張。

*證明。* 對任意 $j > i$，排序保證 $l_j \ge l_i > R$，故 $[l_j, r_j] \cap [L, R] = \varnothing$。$\square$

**這條引理正是「一次線性掃描就夠、不必回頭」的全部依據，而它依賴的前提是「按左端點排序」。** 換成按右端點排序，$l_j \ge l_i$ 不再成立，反例：$[0,10], [1,2], [3,4]$ 按右端點排序成 $[1,2],[3,4],[0,10]$，掃到 $[3,4]$ 時會誤判 $[1,2]$ 已完結。**排序鍵不是隨便挑的，它是正確性的前提。**

（順帶一提：**按右端點排序**是另一族問題——無重疊區間的最大選取數、435、452 射氣球——的正確性前提。**看到「區間 + 排序」先問一句：這題的貪心是靠左端點還是右端點？**）

**引理 2（同座標事件的處理順序 = 區間的開閉語意）。**

考慮兩個區間 $[1,5]$ 與 $[5,9]$，問「最大同時重疊數」。

- 若端點是**閉區間**且「在 5 這一刻兩者都算存在」（如 2021 街上最亮的位置：燈的照射範圍是閉區間），答案是 2。此時 $-1$ 事件應放在座標 $r+1 = 6$，與 $+1$ 事件天然不會撞在一起。
- 若語意是**半開** $[l, r)$（如會議室：09:00–10:00 與 10:00–11:00 不衝突），答案是 1。此時 $-1$ 事件放在座標 $r$，**必須讓同座標的 $-1$ 先於 $+1$ 被處理**，否則 `cur` 會短暫衝到 2 而被誤記錄。

*結論*：把 $-1$ 放在 $r+1$（閉）或 $r$（半開）、以及同座標時 $-1$ 是否先行，這兩個決定**共同編碼了區間的開閉語意**。實作上有兩種等價寫法，二選一，不要混用：

1. 只調整放置座標（$r$ vs $r+1$），排序時同座標**一次批次處理完再取值**；
2. 排序鍵用 `pair(coord, delta)`——`delta = -1` 自然排在 `+1` 前面——然後逐個事件處理。

**寫法 2 只在半開語意下正確**，因為它硬性規定了「先減後加」。閉區間語意用寫法 1。**這是掃描線最常見的錯誤來源，而它不是 bug，是語意沒想清楚。**

**引理 3（798：讓 $i$ 不得分的輪調量構成 $\mathbb{Z}_n$ 上一段連續區塊）。**

輪調量 $k$ 時，原本在下標 $i$ 的元素移到下標 $j = (i - k) \bmod n$，得分條件是 $A_i \le j$。

故「不得分」$\iff j \in \{0, 1, \dots, A_i - 1\}$。由 $k = (i - j) \bmod n$，不得分的 $k$ 集合是
$$\{\, (i - j) \bmod n \;:\; 0 \le j < A_i \,\} \;=\; \{\, i,\ i-1,\ \dots,\ i - A_i + 1 \,\} \bmod n,$$
即**以 $i$ 為右端、長度恰為 $A_i$ 的一段循環連續區塊**（$A_i = 0$ 時為空）。$\square$

於是：初始所有 $k$ 的分數都是 $n$，對每個 $i$ 在上述區塊上 $-1$，最後取最大分數中最小的 $k$。**跨越 0 的區塊要拆成 $[\,(i-A_i+1) \bmod n,\ n-1\,]$ 與 $[\,0,\ i\,]$ 兩段**——差分陣列是線性的，環狀必須拆開（或把陣列加倍）。這是把差分用在答案軸上的最乾淨的例子。

**引理 4（1674：每一對的代價對目標和 $T$ 是分段常數）。**

配對 $(a, b) = (\mathrm{nums}_i, \mathrm{nums}_{n-1-i})$，每個元素可改成 $[1, \mathrm{limit}]$ 中任意值。令 $\mathrm{lo} = \min(a,b)$、$\mathrm{hi} = \max(a,b)$。則把這一對的和變成 $T$ 所需的最少修改次數是

$$\mathrm{cost}(T) = \begin{cases} 0, & T = a + b,\\ 1, & \mathrm{lo} + 1 \le T \le \mathrm{hi} + \mathrm{limit},\ T \ne a+b,\\ 2, & \text{其他}. \end{cases}$$

*證明。* $T = a+b$ 顯然不用改。只改一個元素時，保留其中一個 $x \in \{a,b\}$，另一個設為 $T - x$，需 $1 \le T - x \le \mathrm{limit}$，即 $T \in [x+1,\ x+\mathrm{limit}]$。兩種保留選擇的聯集是 $[\mathrm{lo}+1, \mathrm{lo}+\mathrm{limit}] \cup [\mathrm{hi}+1, \mathrm{hi}+\mathrm{limit}] = [\mathrm{lo}+1, \mathrm{hi}+\mathrm{limit}]$——**聯集之所以連續，是因為 $\mathrm{hi} + 1 \le \mathrm{lo} + \mathrm{limit} + 1$（由 $\mathrm{hi} \le \mathrm{limit}$、$\mathrm{lo} \ge 1$），兩段有重疊或相接。** 兩個都改則任何 $T \in [2, 2\cdot\mathrm{limit}]$ 都做得到，故其餘情形是 2。$\square$

於是總代價 $\mathrm{Cost}(T) = \sum_i \mathrm{cost}_i(T)$：先令全部為 $2n/2$，再對每對在 $[\mathrm{lo}+1, \mathrm{hi}+\mathrm{limit}]$ 上 $-1$、在單點 $T = a+b$ 上再 $-1$。一次差分 + 一次掃描，$O(n + \mathrm{limit})$。**「兩段的聯集恰好連續」這個小事實是能用單一區間加值的前提；若 $\mathrm{hi} - \mathrm{lo} > \mathrm{limit}$（在本題的約束下不可能），就得拆成兩段。**

**引理 5（995：由左至右的貪心翻轉唯一且最優）。**

要把 0/1 陣列全變成 1，每次只能翻轉長度為 $k$ 的連續段。

*宣稱*：從左掃描，若當前位置（考慮既有翻轉後）為 0，則**必須**在此處起一段翻轉。

*證明。* 位置 $i$ 只能被左端點在 $[i-k+1, i]$ 的翻轉影響。由左至右處理到 $i$ 時，左端點 $< i$ 的翻轉都已決定，而位置 $i$ 若仍是 0，唯一還能改變它的是左端點恰為 $i$ 的翻轉。故此翻轉是被**強制**的，不存在選擇，也就談不上「更好的選擇」。$\square$

*差分在這裡的角色*：需要 $O(1)$ 知道「位置 $i$ 目前被翻轉了幾次」。用差分陣列 `diff`，起一段翻轉時 `diff[i] += 1; diff[i+k] -= 1;`，掃描時滾動累加 `flip += diff[i]`，當前值就是 `a[i] ^ (flip & 1)`。**這是差分與滑動視窗的混合：邊決策邊維護，而非最後才還原。** 3.1.1 說「操作與查詢分階段」是划算與否的判準——這裡查詢是嚴格由左至右的，每個位置只查一次，所以仍然是 $O(n)$。

## 時間與空間複雜度

| 形態 | 時間 | 空間 | 備註 |
| --- | --- | --- | --- |
| 事件掃描（vector + sort） | $O(n\log n)$ | $O(n)$ | 與值域無關 |
| 事件掃描（`std::map`） | $O(n\log n)$ | $O(n)$ | 常數大 2–5 倍，但支援線上插入 |
| 合併區間 56/57/759 | $O(n\log n)$ | $O(n)$ | 排序主導；57 若輸入已排序可 $O(n)$ |
| 答案軸差分（798、1674） | $O(n + V)$ | $O(V)$ | $V$ = 候選答案個數 |
| 差分 + 由左至右貪心（995、3356） | $O(n)$ | $O(n)$ | 滾動累加，不需回頭 |
| 二分答案 + 差分（2528、3356） | $O(n\log V)$ | $O(n)$ | 每次判定 $O(n)$ |

**答案軸差分與「對每個候選答案暴力算」的落差**：1674 暴力是 $O(n \cdot \mathrm{limit})$（$10^5 \times 10^5 = 10^{10}$），差分是 $O(n + \mathrm{limit}) = 2\times10^5$。**這是本節最大的槓桿。**

**事件掃描的排序可否省掉？** 若座標本身有界且密集，直接用 3.1.1 的陣列版 $O(n + V)$ 更快（省掉 $\log$）。**判準只有一個：$V$ 開不開得下。** $V \le 10^7$ 大致是分水嶺。

## 與相似技巧的比較

- **與 3.1.1**：事件掃描 = 差分陣列的稀疏版本，兩者不變量完全相同。**先想陣列版，開不下才升級。**
- **與 3.2 二維差分**：矩形加值的稀疏版是「掃描線 + 線段樹」（850 矩形面積 II），因為兩個維度中只有一維能靠排序處理，另一維仍需資料結構。**一維事件掃描不需線段樹，二維就需要——這是維度帶來的真實成本。**
- **與 sorting 主題的區間貪心**：56/57 是「合併」，435/452 是「選最多不重疊」。**合併靠左端點排序，選取靠右端點排序**，兩者的正確性前提相反，不要互抄。
- **與 6.x 堆**：253（會議室 II）可以用「最小堆維護各會議室的結束時間」解，也可以用事件掃描。**事件掃描只回答「最多幾間」，堆還能回答「每間分別是誰」。要輸出分配方案就得用堆。**
- **與二分答案**：2528、3356 的形態是「答案單調 + 判定用差分 $O(n)$」。**判定函數能不能寫成一次差分掃描，往往決定這題可不可做。**
- **與 1589（所有排列中的最大和）**：先用差分算出每個下標被查詢覆蓋的次數 $c_i$，再把大的 $\mathrm{nums}$ 配給大的 $c$。最優性來自**排序不等式**（交換論證：若 $c_p > c_q$ 卻把小值配給 $p$，交換後總和不減）。**差分只負責算出 $c$，最優性是另一段獨立的論證——別把兩件事混成一句「排序就好」。**

## 本節重點速查

事件掃描 = 差分的稀疏表示：$[l,r]$ 加 $v$ ⇒ 事件 $(l,+v)$、$(r{+}1,-v)$，排序後累加。**與值域無關，$O(n\log n)$。**
**同座標事件的處理順序就是區間的開閉語意**：閉區間 ⇒ $-1$ 放 $r+1$ 且同座標批次處理完再取值；半開 ⇒ $-1$ 放 $r$ 且排序時 $-1$ 先行。二選一，不要混。
合併區間靠**左端點**排序（引理 1：$l_j \ge l_i > R$ ⇒ 不必回頭）；選最多不重疊靠**右端點**排序。**排序鍵是正確性前提。**
**差分可以做在「答案軸」上**：798 對輪調量、1674 對目標和、2528 對位置。訊號是「每個元素對每個候選答案的貢獻是分段常數」。
798 的不得分區塊是以 $i$ 為右端、長度 $A_i$ 的循環段；**環狀要拆兩段或倍長。**
1674 的三段代價：$0$ / $1$（$[\mathrm{lo}+1, \mathrm{hi}+\mathrm{limit}]$）/ $2$；聯集連續是能用單一區間加值的前提。
995 的由左至右貪心是**被強制的**（位置 $i$ 只剩左端點為 $i$ 的翻轉能救），差分負責 $O(1)$ 查當前翻轉次數。
$V$ 開得下就用陣列（$O(n+V)$，省一個 $\log$）；開不下才用排序或 `map`。
