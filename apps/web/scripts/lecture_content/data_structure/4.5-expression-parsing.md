## 這個技術解決什麼問題

輸入是一串要「按規則計算或驗證」的字元，而且帶有**優先級**或**巢狀**結構：224／227（基本計算器）、150（逆波蘭表示式）、394（字串解碼）、726（原子的數量）、736（Lisp 語法解析）、1106（解析布林表示式）、8（atoi）、65（有效數字）。

暴力做法（反覆掃描找優先級最高的運算子再計算）是 $O(n^2)$，而且遇到巢狀括號就難以維護。

正確的思路是把題目當成**一個小型編譯器前端**：先寫下文法，再選一種實作（遞迴下降或顯式堆疊）。**幾乎所有解析題的困難都不在程式碼，而在沒有先把文法與優先級寫清楚就開始寫 `if`。**

本節的核心觀念只有兩個：

1. **優先級決定「什麼時候可以結算」。** 高優先級的運算子必須立刻結算，低優先級的要等。
2. **巢狀決定「什麼時候要保存現場」。** 進入括號時把當前的部分結果推入堆疊，離開時取回並合併——這就是遞迴呼叫堆疊的手動版。

## 狀態／資料結構定義

**先寫文法。** 四則運算帶括號的標準文法（左結合）：
```
expr   → term (('+' | '-') term)*
term   → factor (('*' | '/') factor)*
factor → number | '(' expr ')' | '-' factor      // 最後一項是一元負號
```
**這三行決定了一切**：優先級由層級表示（`factor` 綁最緊），左結合由 `*` 迴圈（而非右遞迴）表示。

**實作一：遞迴下降。** 三個函式對應三條規則，共用一個 `size_t i` 當游標（用成員變數或以參考傳遞）。**最貼近文法、最好除錯，但受遞迴深度限制**（`((((...))))` 深度 $10^5$ 會爆棧）。

**實作二：單一數值堆疊（227，無括號）。**
- `vector<long long> st`：已完成的**加法項**，符號已折進數值。
- `char op = '+'`：上一個看到的運算子。
- 每讀完一個數 `num`，依 `op` 動作：`+` 推入 `num`；`-` 推入 `-num`；`*` 令 `st.back() *= num`；`/` 令 `st.back() /= num`。
- 答案 = `st` 的總和。

**實作三：符號堆疊（224，有括號但只有 `+ -`）。**
- `int sign = 1`、`long long res = 0`、`vector<int> st`（保存進入括號前的 `res` 與 `sign`）。
- `(` 時推入 `res` 與 `sign`，然後重置 `res = 0, sign = 1`；`)` 時 `res = 前res + 前sign * res`。

**實作四：狀態堆疊（394 字串解碼）。** 堆疊元素是 `pair<int, string>`：進入 `[` 時推入「當前重複次數」與「已累積的字串」，離開 `]` 時取回並拼接。

**共同模式：括號 = 保存現場 + 遞迴 + 合併。** 四種實作只是「現場」的內容不同。

**數字的讀取要一次讀完整個 token**，不要一位一位混進主迴圈：`while (i < n && isdigit(s[i])) num = num * 10 + (s[i++] - '0');`。**多位數是解析題第一個踩雷處。**

## 不變量或正確性證明

### 定理 1（227 的堆疊不變量：優先級決定結算時機）

**不變量**：處理完某個加法項之後，
$$\texttt{sum(st)} \;=\; \text{目前已完整讀入的算式前綴之值}.$$

*證明（對加法項數歸納）。* 基底：`st` 為空，值為 0 ✔。歸納步：設已處理的前綴值等於 `sum(st)`。接著讀到 `op` 與 `num`：
- `op` 是 `+` 或 `-`：這開啟一個**新的加法項**，其值目前是 $\pm\texttt{num}$，推入後總和恰好增加 $\pm\texttt{num}$ ✔。
- `op` 是 `*` 或 `/`：由文法，`*`／`/` 綁得比 `+`／`-` 緊，所以 `num` 屬於**當前這個加法項**，而該項的值正是 `st.back()`。就地修改 `st.back()` 等於修改該項的值，總和隨之正確更新 ✔。$\square$

**這條論證點名了兩個前提。**

1. **`*`／`/` 的優先級嚴格高於 `+`／`-`。** 這保證了「看到 `*` 時，要相乘的左運算元一定是最近推入的那一格」。若優先級相同（如把 `*` 改成同級），`st.back()` 就未必是正確的左運算元。
2. **左結合。** `8 / 3 / 2` 必須是 $(8/3)/2 = 1$，而 `st.back() /= num` 依序執行正好給出左結合。**若某個運算子是右結合（如次方 `^`），就不能就地修改，必須改用另一個堆疊或遞迴。**

*推論*：一個加法項一旦看到下一個 `+`／`-`（或字串結束），就**確定不會再被修改**——因為之後的任何運算子都綁得不比 `+` 緊。**「什麼時候可以安全結算」永遠由『後面還有沒有可能綁更緊的東西』決定，這是所有優先級解析的共同原理。**

*整數除法的方向*：C++ 的 `/` 對負數是向零截斷（`-7/2 == -3`），與 LeetCode 227 的要求一致。**但 166、29 等題要的是向下取整，必須自己處理**——別假設語言的預設就是題目要的。

### 定理 2（150 逆波蘭：合法性的線性刻畫）

給 token 定義權重：運算元 $w = +1$，$k$ 元運算子 $w = -(k-1)$（二元運算子即 $-1$）。

**宣稱**：一個 token 序列是合法的後綴表示式 $\iff$ **每個非空前綴的權重和 $\ge 1$，且總和恰為 $1$。**

*（$\Rightarrow$）* 對表示式樹歸納：權重和 = 求值後堆疊上的元素個數。單一運算元為 1；$E_1 E_2 \oplus$ 的權重和 $= 1 + 1 - 1 = 1$。任一前綴對應「若干棵已完成的子樹 + 一棵未完成的」，個數 $\ge 1$。

*（$\Leftarrow$）* 對長度歸納：末尾 token 若是運算元則其前綴總和為 0，違反「$\ge 1$」除非序列長度為 1；若是二元運算子，把序列從右往左找出最後一個使前綴和為 1 的切點，可拆成兩段各自合法。$\square$

**這條定理與 4.4 的定理 1 是同一件事的推廣**：括號的 $\mathrm{bal} \ge 0$ 與 $\mathrm{bal}_{\text{final}} = 0$，在這裡變成權重和 $\ge 1$ 與 $= 1$。**「堆疊高度的前綴約束」是所有巢狀結構合法性的統一刻畫。**

*求值的不變量*：處理完某前綴後，數值堆疊由底到頂 = 該前綴中**所有極大完整子表示式**的值，順序與原文一致。遇到二元運算子時彈出兩個——**先彈出的是右運算元**，這是減法與除法出錯的第一名原因。

### 定理 3（394 字串解碼的深度不變量）

**不變量**：堆疊第 $d$ 格（由底算起）保存「深度 $d$ 這一層在進入第 $d+1$ 層之前已經累積好的字串」與「第 $d+1$ 層的重複次數」；變數 `cur` 保存**當前最深層**已累積的字串。

*維持*：讀到 `k[` 時，當前層的 `cur` 已完成到此，連同 `k` 一起推入，`cur` 重置為空（開新層）；讀到 `]` 時，彈出 $(k, \text{prev})$，令 `cur = prev + repeat(cur, k)`（合併回父層）。

*正確性*：這正是文法 $S \to (\text{letters} \mid \text{num} [\,S\,])^*$ 的結構歸納——每個 `]` 恰好閉合最近一個未閉合的 `[`（4.4 定理 1 保證輸入良括號），而閉合時子層的值已經完整。$\square$

**這個不變量的價值在於它說清楚了「`cur` 不在堆疊裡」**。初學者常把 `cur` 也推入堆疊，導致多一層或少一層。**記法：堆疊存的是「父層的殘缺結果」，`cur` 存的是「當前層的殘缺結果」，兩者永遠差一層。**

### 定理 4（8 atoi 的溢位判定）

累加 `res = res * 10 + d` 之前必須檢查，而**檢查必須在乘法之前做**——溢位一旦發生就是未定義行為，事後檢查沒有意義。

正數方向的正確條件是
$$\texttt{res} > \frac{\texttt{INT\_MAX} - d}{10} \quad\Longrightarrow\quad \text{溢位（夾到 INT\_MAX）}.$$

*正確性*：$\texttt{res}\cdot 10 + d > \texttt{INT\_MAX} \iff \texttt{res} \cdot 10 > \texttt{INT\_MAX} - d \iff \texttt{res} > \frac{\texttt{INT\_MAX}-d}{10}$。最後一步的整數除法向下取整不會出錯，因為 $\texttt{res}$ 是整數：$\texttt{res} > \lfloor y/10 \rfloor \iff 10\,\texttt{res} > y$ 對整數 $\texttt{res}$、$y$ 成立（$10\,\texttt{res} > y \iff \texttt{res} > y/10 \iff \texttt{res} \ge \lfloor y/10\rfloor + 1$）。$\square$

**更簡單且同樣正確的做法是全程用 `long long` 累加，並在超過 $2^{31}$ 時提早夾住**（因為輸入長度有限，`long long` 不會溢位）。**但面試常要求不用更寬的型別，那就得寫上面那條不等式——而且要能說出它為什麼對。**

*負數方向*：常見做法是統一以正數累加、最後套符號，此時上界要用 $|\texttt{INT\_MIN}| = 2147483648$，**不能直接用 `INT_MAX`**，否則輸入 `-2147483648` 會被錯誤夾成 `-2147483647`。

## 時間與空間複雜度

| 題目 | 方法 | 時間 | 空間 |
| --- | --- | --- | --- |
| 150 RPN | 單一數值堆疊 | $O(n)$ | $O(n)$ |
| 227（無括號） | 單一數值堆疊 | $O(n)$ | $O(n)$；可優化到 $O(1)$（見下） |
| 224（有括號、只有 `+ -`） | 符號堆疊 | $O(n)$ | $O(\text{深度})$ |
| 224 + 227 合體 | 遞迴下降 / 狀態堆疊 | $O(n)$ | $O(\text{深度})$ |
| 394 字串解碼 | 狀態堆疊 | $O(\text{輸出長度})$ | $O(\text{輸出長度})$ |
| 8 / 65 | 狀態機 | $O(n)$ | $O(1)$ |
| 726 原子的數量 | 堆疊 + `map` | $O(n^2)$ 或 $O(n\log n)$ | $O(n)$ |

**227 可以做到 $O(1)$ 空間**：不必真的存下所有加法項，只要維護「已完成項的總和 `sum`」與「當前項的值 `cur`」兩個變數即可——**這是定理 1 不變量的直接推論（我們只需要總和，不需要個別項）。** 又一次「同質元素只問聚合值 ⇒ 堆疊可降級」的例子（4.1、4.4 都出現過）。

**394 的複雜度是輸出長度而非輸入長度**：`10[10[10[ab]]]` 的輸入是常數級，輸出是 2000 個字元。**估計複雜度時要以輸出為準**，這也是為什麼這類題目會限制輸出長度。

**726 的 $O(n^2)$ 來自字串拼接與 `map` 合併**：把子層的 `map` 併入父層時，最壞情況每層都要複製整個 `map`。用「一個全域 `map` + 乘數堆疊」可以降到 $O(n\log n)$。

**遞迴下降的深度風險**：`(((...)))` 巢狀 $10^5$ 層時遞迴會爆棧。**顯式堆疊沒有這個問題**，這是它唯一的實質優勢；其餘情況遞迴下降都更好寫。

## 與相似技巧的比較

- **與 4.4 括號**：4.4 只判斷結構是否合法，本節在合法結構上求值。**定理 2 顯示兩者的合法性刻畫是同一條「堆疊高度前綴約束」。**
- **與 4.3 鄰項消除**：4.3 的消除是無結構的（只看相鄰），本節有優先級與巢狀。**看到優先級就別想套 4.3 的模板。**
- **與遞迴**：遞迴下降與顯式堆疊嚴格等價，堆疊格 = 呼叫框架，格內容 = 區域變數。**先用遞迴下降寫對，再視深度需求改寫成堆疊。**
- **與 4.2 設計題**：394、726 的堆疊放的是「整包狀態」，與 4.2 的 636（呼叫鏈）同一種用法。
- **與雙堆疊法（調度場演算法）**：處理任意優先級表時的通用解——一個運算元堆疊、一個運算子堆疊，遇到優先級不高於棧頂的運算子就先結算。**題目只有兩層優先級時（227），單堆疊法更短；優先級超過兩層或要支援右結合、一元運算子時，雙堆疊更不容易錯。**
- **與狀態機（8、65）**：這兩題沒有巢狀，只有「合法的字元順序」，用 DFA（狀態轉移表）最清楚。**沒有巢狀就不需要堆疊——別把所有解析題都當成括號題。**

## 本節重點速查

**動筆前先寫文法**：`expr → term (('+'|'-') term)*`、`term → factor (('*'|'/') factor)*`、`factor → number | '(' expr ')' | '-' factor`。優先級 = 層級，左結合 = 迴圈。
**兩個原理**：優先級決定「何時可安全結算」（後面不可能出現綁更緊的東西時）；巢狀決定「何時保存現場」。
227 的不變量：`sum(st)` = 已讀前綴之值。`+/-` 推入新項、`*//` 就地改 `st.back()`。**前提是 `*//` 優先級更高且左結合。** 只要總和 ⇒ 可降級成兩個變數，$O(1)$ 空間。
150 的合法性（定理 2）：運算元 $+1$、二元運算子 $-1$，**每個前綴和 $\ge 1$ 且總和 $= 1$**；求值時**先彈出的是右運算元**。
394：堆疊存「父層殘缺結果 + 重複次數」，`cur` 存當前層；**兩者永遠差一層**。複雜度以**輸出長度**計。
8 的溢位檢查必須在乘法**之前**：`res > (INT_MAX - d) / 10`；負數方向的上界是 $2147483648$，不是 `INT_MAX`。
多位數要一次讀完整個 token。整數除法方向（截斷 vs 向下）要看題目，不要假設。
遞迴下降最好寫、受深度限制；顯式堆疊不怕深度。優先級超過兩層或有右結合時改用雙堆疊（調度場）。
沒有巢狀的解析題（8、65）用狀態機，不需要堆疊。
