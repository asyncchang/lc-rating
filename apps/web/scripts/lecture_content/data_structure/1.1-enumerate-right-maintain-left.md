## 這個技術解決什麼問題

「找出滿足某條件的一對下標 $(j, i)$，其中 $j < i$」是最常見的題型之一（1 兩數之和、121 買賣股票、219 鄰近重複、454 四數相加）。樸素做法是雙層迴圈，$O(n^2)$。

真正的浪費在哪裡？對每個右端點 $i$，內層迴圈都把 $[0, i)$ 重掃一遍。但相鄰兩次掃描的範圍只差一個元素——**$99\%$ 的工作是重複的**。

本節的技巧就是把「重掃左側」換成「維護一份左側摘要」：摘要在掃描過程中增量更新，每次 $O(1)$；查詢也是 $O(1)$。$O(n^2) \to O(n)$。

## 狀態／資料結構定義

- **列舉變數**：下標 $i$，代表「右端點」。
- **左側摘要** $M_i$：一個只依賴 $\{a_0, \dots, a_{i-1}\}$ 的資料結構。常見形態：
  - `unordered_map<int,int> seen`：值 → 最後出現的下標（題 1、219）。
  - `unordered_map<int,int> cnt`：值 → 出現次數（計數型，題 1512、2364）。
  - 單一純量 `minSoFar` / `maxSoFar`：左側的極值（題 121、2016）。
- **查詢介面**：給定右端點 $a_i$，能 $O(1)$ 從 $M_i$ 取出「有多少 / 有沒有 / 最好的」左端點。

摘要的形態由「右端點需要知道左側的什麼」反推，而不是先選容器再想用途。

## 不變量或正確性證明

**不變量。** 在迴圈第 $i$ 輪執行「查詢」那一行的瞬間，摘要 $M$ 恰好等於 $f(a_0, a_1, \dots, a_{i-1})$——**包含全部下標嚴格小於 $i$ 的元素，且不包含 $a_i$ 自己**。

- 初始化：$i = 0$ 時 $M$ 為空，對應空集合。成立。
- 保持：第 $i$ 輪先查詢（此時 $M$ 仍是第 $i-1$ 輪結束時的狀態，即 $\{a_0..a_{i-1}\}$），查完才把 $a_i$ 併入，使 $M$ 變成 $\{a_0..a_i\}$，正是第 $i+1$ 輪所需。

**不重不漏。** 每個合法的配對 $(j, i)$ 且 $j < i$，恰在「處理右端點 $i$」時被統計一次：
- *不漏*：$j < i \Rightarrow a_j$ 在第 $i$ 輪查詢前已進入摘要。
- *不重*：每對配對只有唯一的較大下標 $i$，而統計只在右端點發生。

**這條論證點名了兩個前提。**

1. **「先查詢、再加入」的順序不可交換。** 若先加入再查詢，$M$ 就變成 $\{a_0..a_i\}$，會把 $(i, i)$ 這個非法的「自己配自己」算進去。題 1 若寫反，`nums = [3,3], target = 6` 會回傳 `[0,0]`。
2. **摘要必須可增量維護。** 「把 $a_i$ 併入 $M$」必須是 $O(1)$（或至少遠小於重算）。若題目要的左側資訊是「左邊的中位數」，加入一個元素不是 $O(1)$，就得換成對頂堆（見 6.7），本節的骨架仍在但成本改變。

**極值型（題 121）的變體證明。** 令 $m_i = \min_{j<i} a_j$。遞推 $m_{i+1} = \min(m_i, a_i)$ 顯然正確，且答案 $\max_i (a_i - m_i)$ 覆蓋了所有 $j < i$ 的配對——因為對固定的 $i$，$a_i - a_j$ 在 $a_j = m_i$ 時最大。**這一步用到「對固定右端點，最佳左端點只有一個，不必記住全部」**，這是把 map 換成純量的依據；一旦題目改成「第二便宜的那天」，這個依據就失效。

## 時間與空間複雜度

主迴圈 $n$ 輪，每輪 $O(1)$ 攤銷（雜湊表的查詢與插入是期望 $O(1)$），總計 **$O(n)$ 時間**。

空間 $O(\min(n, |V|))$，$|V|$ 是值域中實際出現的相異值個數。極值型是 $O(1)$。

**注意雜湊表的常數。** `unordered_map<int,int>` 的單次操作常數約是陣列的 5–20 倍。若值域已知且不大（如題 1010 的餘數只有 60 種、字元只有 26 種），改用 `vector<int>` 或固定大小陣列可以快數倍——這在 $n$ 達 $10^6$ 時是能否卡過的差別。

題 454（四數相加 II）是把 $O(n^4)$ 拆成兩半：先用 $O(n^2)$ 建 `A+B` 的和的計數表，再用 $O(n^2)$ 枚舉 `C+D` 查表，總計 $O(n^2)$ 時間與空間。**這是「把配對的兩邊各自預處理」的推廣，與 4.8 的折半列舉同源。**

## 與相似技巧的比較

- **與雙指標／滑動視窗**：滑動視窗要求左端點隨右端點**單調移動**，依賴「加入元素使某量單調變化」的性質，因此怕負數。本節不要求單調，只要求「左側資訊可增量維護」，所以有負數也能用（見 2.2）。
- **與排序 + 二分**：若允許打亂順序，排序後用二分或雙指標也能解兩數之和，$O(n \log n)$。但**排序會破壞下標**，題目若要回傳原始下標就得額外記錄。本節保序且更快。
- **與 1.3 列舉中間**：本節固定右端點、維護一側；1.3 固定中間、維護兩側。判準是「特殊角色的那個元素在配對的哪個位置」。
- **與前綴和 + 雜湊表（2.2）**：那是本節的直接應用——把 $a_i$ 換成前綴和 $s_i$，把「配對」換成「$s_i - s_j = k$」。**2.2 不是新技巧，是本節套在前綴和序列上。**
- **與 DP**：`minSoFar` 其實就是一個一維 DP 狀態。當左側摘要是純量且有遞推式時，這個技巧與「滾動變數 DP」是同一件事。

## 本節重點速查

把雙層迴圈的內層換成**增量維護的左側摘要**：$O(n^2) \to O(n)$。
不變量：查詢的那一刻，摘要恰好是 $\{a_0, \dots, a_{i-1}\}$——**不多不少**。
紀律只有一條：**先查詢、再加入**。反了就會「自己配自己」。
摘要形態由「右端點需要知道左邊的什麼」反推：要值 → map；要個數 → 計數表；要最好的一個 → 純量。
用純量取代 map 的依據是「對固定右端點，最佳左端點唯一」；題目一改就要重新檢查。
值域小時用陣列取代 `unordered_map`，常數差好幾倍。
