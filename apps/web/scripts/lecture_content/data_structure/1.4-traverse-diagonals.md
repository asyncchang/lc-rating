## 這個技術解決什麼問題

矩陣題若要「沿對角線」處理（498 對角線遍歷、1329 按對角線排序、3446 按對角線排序、2711 對角線相異值、562 最長連續 1 線段、面試題 17.23 最大黑方陣），直覺寫法是「找到每條對角線的起點，然後 `while` 迴圈 `++i, ++j` 走到出界」。起點的計算分成「第一行」與「最後一列」兩段，$m \ne n$ 時邊界極易寫錯。

本節要建立的是一個更省事的視角：**同一條對角線上的格子有一個共同的整數編號，於是「沿對角線處理」等價於「按編號分組」**。分組之後，二維問題就變成一堆一維問題，邊界問題全部消失。

## 狀態／資料結構定義

對 $m \times n$ 矩陣中的格子 $(r, c)$，$0 \le r < m$、$0 \le c < n$：

- **主對角線（↘，往右下）編號**：$d_1 = r - c$，範圍 $[-(n-1), m-1]$，共 $m + n - 1$ 條。
- **副對角線（↙／↗，往右上）編號**：$d_2 = r + c$，範圍 $[0, m+n-2]$，共 $m + n - 1$ 條。

負編號有兩種處理：用 `map<int, vector<int>>`（自動排序，$O(\log)$），或**加偏移量** $d_1 + n - 1 \in [0, m+n-2]$ 後用 `vector<vector<int>>`（$O(1)$，常數小得多，推薦）。

**每條對角線內的順序**：按 $r$ 遞增即是「從左上往右下」。分組時只要外層 `for r`、內層 `for c`，`push_back` 的順序天然就是 $r$ 遞增，不需額外排序。

## 不變量或正確性證明

**引理（對角線的判準）。** 兩個格子 $(r_1,c_1)$、$(r_2,c_2)$ 在同一條 ↘ 對角線上 $\iff r_1 - c_1 = r_2 - c_2$；在同一條 ↗ 對角線上 $\iff r_1 + c_1 = r_2 + c_2$。

*證明。* ($\Rightarrow$) 沿 ↘ 方向移動一步是 $(r,c) \to (r+1, c+1)$，$r - c$ 是這個變換的不變量；沿路徑走 $t$ 步後仍相等。
($\Leftarrow$) 設 $r_1 - c_1 = r_2 - c_2$，令 $t = r_2 - r_1$。由等式得 $c_2 - c_1 = t$，故從 $(r_1,c_1)$ 沿 ↘ 走 $t$ 步（$t<0$ 則往 ↖ 走 $|t|$ 步）恰好到達 $(r_2,c_2)$，且路徑上每一格都在矩陣內（因為 $r$ 從 $r_1$ 單調走到 $r_2$、$c$ 同步，兩端都在界內，中間必然也在）。↗ 同理，此時 $c_2 - c_1 = -t$。$\square$

**這條引理點名了它依賴的前提：矩陣是「矩形」的。** 中間走過的格子必定在界內，用到的是 $[0,m) \times [0,n)$ 這個區域對「兩端點在內則線段在內」封閉（凸性）。若題目給的是不規則的鋸齒陣列（每列長度不同），$r - c$ 相同的兩格未必真的沿對角線相連，這個判準就不能直接用。

**分組法與「順著走」等價。** 定義映射 $(r,c) \mapsto (d_1, r) = (r - c, r)$。它是單射（由 $d_1$ 與 $r$ 唯一還原 $c = r - d_1$），因此把每格放進 `diag[d1]` 並按 $r$ 排序，得到的就是「順著對角線從左上走到右下」的序列，一格不多一格不少。$\square$

**1329／3446（按對角線排序）的正確性。** 收集 → 排序 → 寫回，三步。寫回時必須**用與收集時完全相同的走訪順序**，否則會把排好的值填錯位置。最穩妥的寫法是為每條對角線維護一個游標 `idx[d]`，收集與寫回都用同一組雙層迴圈：因為映射是單射，第二次雙層迴圈訪問 $(r,c)$ 時取到的 `diag[d1][idx[d1]++]` 必定對應同一個位置。**不要在寫回時改用「順著走」的迴圈**——順序看似一樣，但一旦某條對角線的起點算錯，錯誤會非常隱蔽。

**498（鋸齒對角線遍歷）的方向規則。** 題目要求編號 $s = r + c$ 為**偶數**時由左下往右上（$r$ 遞減），奇數時由右上往左下（$r$ 遞增）。若按 $r$ 遞增收集，則偶數條需要 `reverse`。驗證：$s = 0$ 只有 $(0,0)$；$s = 1$ 應輸出 $(0,1), (1,0)$，即 $r$ 遞增，符合「奇數不反轉」。**這種「規則從第一個例子反推」的驗證，比記憶方向可靠。**

**562（最長連續 1 線段）四個方向的統一。** 水平（$c$ 遞增，鍵是 $r$）、垂直（$r$ 遞增，鍵是 $c$）、↘（鍵 $r-c$）、↗（鍵 $r+c$）。四個方向用同一套「按鍵分組 + 在組內求最長連續 1」的骨架，只換鍵與組內順序。**這說明「對角線」不是特例，而是「按線性函數分組」這個更一般模式的四個實例。**

## 時間與空間複雜度

**分組**：每格恰被訪問一次，$O(mn)$ 時間、$O(mn)$ 空間。

**分組後的處理**：
- 只掃描 / 求最值 / 前綴和：$O(mn)$。
- 每條對角線排序：設第 $t$ 條長度 $\ell_t$，總計 $\sum_t \ell_t \log \ell_t \le (\sum_t \ell_t) \log(\max_t \ell_t) = O(mn \log \min(m,n))$。**注意上界是 $\log \min(m,n)$ 而不是 $\log(mn)$**——最長的對角線只有 $\min(m,n)$ 格。$m=n=100$ 時這個差別是 $\log 100 \approx 7$ 對上 $\log 10^4 \approx 13$。
- 每條對角線內求相異值個數（2711）：用 `unordered_set` 或 26 位元的 `bitset` 掃兩遍（前綴相異數 + 後綴相異數），$O(mn)$。

**空間可以省。** 若只需要順序輸出（498），不必真的建 `vector<vector<int>>`，直接對每個 $s$ 用內層迴圈枚舉合法的 $r \in [\max(0, s-n+1), \min(m-1, s)]$ 即可，空間 $O(1)$（不計輸出）。**這個範圍公式來自兩個約束 $0 \le r < m$ 與 $0 \le s - r < n$ 的交集**，是「順著走」寫法的無邊界錯誤版本。

## 與相似技巧的比較

- **與 grid 主題的 BFS／DFS**：那是沿四連通或八連通移動，關心的是連通性；本節不做移動，只做分組。**如果題目說「斜向相鄰」但要判連通，那是 DFS，不是本節。**
- **與 1.3 列舉中間**：3128（直角三角形）按「同列」「同行」分組後乘法合併，與本節按 $r \pm c$ 分組是同一個模式（**按線性函數分組，再對每組獨立計數**），只是鍵不同。
- **與 N 皇后（trees 4.5）**：那裡用 $r+c$ 與 $r-c+n-1$ 當衝突標記的下標，依據正是本節的引理。**同一條數學事實，一個拿來分組、一個拿來判衝突。**
- **與二維前綴和（2.6）**：前綴和沿行列方向累積；若題目要的是「沿對角線的前綴和」（如 562、面試題 17.23 的斜向連續段），就要用 `dp[r][c] = dp[r-1][c-1] + 1` 這種**沿對角線的遞推**，本質是在對角線這條一維序列上做前綴，與本節同源。
- **與 map 與陣列的選擇**：$d_1$ 為負是唯一的麻煩。用 `map` 一行搞定但慢；用偏移量 `d1 + n - 1` 配 `vector` 快得多。**題目規模大就一律用偏移量。**

## 本節重點速查

**↘ 對角線 $\iff r - c$ 相同；↗ 對角線 $\iff r + c$ 相同。** 各有 $m+n-1$ 條。
把「沿對角線走」改成「**按編號分組**」，邊界問題全部消失；分組時外層 `for r`、內層 `for c`，組內順序天然是 $r$ 遞增。
$r - c \in [-(n-1), m-1]$ 為負，**加偏移量 $n-1$** 後用 `vector` 比 `map` 快得多。
排序題（1329／3446）**收集與寫回必須用同一組雙層迴圈 + 每條對角線一個游標**，別在寫回時改成「順著走」。
不建表的寫法：對每個 $s = r+c$，合法 $r \in [\max(0, s-n+1), \min(m-1, s)]$——這個範圍來自兩個下標約束的交集。
每條對角線排序的總成本是 $O(mn \log \min(m,n))$，不是 $\log(mn)$。
引理依賴矩陣是矩形（凸的）；鋸齒陣列不適用。
